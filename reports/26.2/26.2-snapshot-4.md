# Minecraft 26.2 Snapshot 4 变更分析

- 上一个版本：`26.2-snapshot-3`
- 当前版本：`26.2-snapshot-4`

## 放置后立即转化的方块会正常扣除物品

本次修改改变了方块放置的成功判定。方块在放入世界后立即变成其他方块，或被用于召唤傀儡时，新版仍将这次放置视为成功，影响湿海绵处理和手动召唤傀儡。

### 差异出现的场景

玩家在生存模式下执行以下操作：

- 在下界放置湿海绵，使它立即变为干海绵。其他具有水蒸发环境属性的位置也适用。
- 将雕刻南瓜或南瓜灯放到已经搭好的对应结构上，成功召唤雪傀儡、铁傀儡或铜傀儡。

### 版本变化

- Snapshot 3：世界中的转化或召唤已经发生，但放置过程因原位置不再是刚放下的方块而返回失败。玩家手中的湿海绵、雕刻南瓜或南瓜灯不会扣除，也不会执行这次手动放置后续的成功结算。
- Snapshot 4：上述情况返回放置成功，正常扣除一个物品，并执行放置声音和放置游戏事件的处理。

### 实际影响

旧版可反复使用同一块湿海绵在下界放出干海绵，也可重复使用同一个南瓜物品手动召唤傀儡；新版这些操作需要消耗对应物品。发射器召唤傀儡原本就会扣除南瓜，不属于此次扣物品差异。

普通 `/setblock` 和 `/fill` 同样会收到新的成功结果。例如在下界放置湿海绵，旧版虽然已经生成干海绵，命令仍可能报告失败；新版将其计入成功设置的方块，影响命令返回值和据此运行的后续命令。`strict` 模式会跳过相关放置回调，不触发这里的转化过程。

## 关闭怪物生成不再拦截常规自然刷怪

常规自然生成不再按“是否允许怪物生成”过滤整个怪物类别。这既让和平难度能够自然生成其中允许在和平难度存在的生物，也使 `spawn_monsters` 规则失去对常规自然刷怪的控制。

### 差异出现的场景

`spawn_mobs` 保持开启，玩家附近存在满足生物自身生成条件、距离条件和生物上限的空间；世界处于和平难度，或将 `spawn_monsters` 设为 `false`。

### 版本变化

- Snapshot 3：和平难度或 `spawn_monsters=false` 会使整个怪物类别跳过常规自然生成。猪灵、疣猪兽、硫方怪虽然能够在和平难度下存活，也不会通过这一流程自然生成。
- Snapshot 4：这层类别过滤被移除。在各自对应的生物群系中，猪灵、疣猪兽和硫方怪能够在和平难度下自然生成。非和平难度下，僵尸、骷髅等也能在 `spawn_monsters=false` 时继续按各自的正常条件自然生成。

生物自己的难度检查仍会执行，因此僵尸等需要非和平难度的生物并不会因此在和平难度生成。`spawn_mobs=false` 仍会关闭这套自然生成流程。幻翼、巡逻队等使用独立生成器的机制仍收到原来的怪物生成开关，此次变化不能推广到所有生成途径。

### 实际影响

依靠 `spawn_monsters=false` 维持无自然怪物环境的世界，在非和平难度下会重新出现常规自然刷怪。和平难度中的下界生物获取、硫方怪收集和对应生物的自动生产，则新增了自然补充来源。

## 破坏复活仪式的末地水晶会立即中止末影龙复活

在末地返回传送门周围放置末地水晶并启动末影龙复活后，破坏参与仪式的水晶，现在能够正确取消仪式。

- Snapshot 3：仪式保存的是水晶引用，破坏时却直接用水晶实体查找，无法识别它是否属于仪式。只要仍有参与仪式的水晶存在，复活动画就可以继续，黑曜石柱仍会继续重建，最终仍能复活末影龙；所有参与水晶都消失时，后续检查才会中止仪式。
- Snapshot 4：按水晶 UUID 匹配仪式记录。破坏其中任意一颗参与仪式的水晶，即刻清除复活阶段和计时，恢复返回传送门，并重置黑曜石柱顶水晶的无敌状态与光束目标。

这使依靠破坏部分仪式水晶取消复活、停止后续黑曜石柱重建的操作恢复生效。已在中止前重建的黑曜石柱不会回退。

## 自然生成的幼年硫方怪使用小体型

同一批自然生成的硫方怪中，被年龄初始化选为幼年的个体，旧版仍使用成年大小；新版先确定年龄，再选择体型。

- Snapshot 3：自然生成的幼年硫方怪与成年个体一样大，最大生命值为 8；它仍按幼年规则接受食物，不能吞入方块。死亡时会因体型较大而分裂。
- Snapshot 4：这类幼年个体的身体宽高减半，最大生命值为 4，使用小体型的声音，死亡时不再分裂。

此处改变的是生成时体型与年龄的对应关系，并未提高抽到幼年个体的概率。已经保存的旧个体会继续读取原有体型，不会仅因升级并加载世界而自动缩小。

## 硫黄洞穴的岩层分布与硫黄尖锥高度改变

在相同种子、相同坐标新生成硫黄洞穴时，新版会得到不同的岩层和尖锥分布：

- 洞穴岩层原本只在普通岩石、朱砂、硫黄之间按噪声切换；新版在过渡区域加入凝灰岩和花岗岩，并重新分配朱砂与硫黄的区间。原先噪声较高处的朱砂区域改为硫黄，部分原有硫黄区域改为朱砂或花岗岩，影响两种建筑材料的分布和采掘位置。
- 硫黄尖锥簇用于生成长度的随机高度参数由 3–6 降为 1–4，生成的尖锥趋于更短。实际每根尖锥还受洞穴空间、簇内位置和随机偏差影响。

这些修改适用于尚未生成的区域，已经生成的洞穴和玩家放置的方块不会被重新替换。在硫黄洞穴延伸到的新旧区块交界处，两侧可能呈现不同的材料分布。

## 缺少 Vulkan 加载器时可以继续尝试 OpenGL

当系统缺少 Vulkan 加载器、但具备可用的 OpenGL 环境时，旧版会在初始化本地库阶段直接失败，尚未进入显卡后端回退流程。新版捕获 Vulkan 加载器的加载失败，跳过依赖它的几个库，再在选择图形后端时将 Vulkan 判为不可用，继续尝试 OpenGL。因此这类环境能够进入游戏。

新版还会在查询 Vulkan 高级特性前跳过仅支持 Vulkan 1.0 的设备。没有合格设备时，错误会通过图形后端创建失败流程处理，并继续尝试 OpenGL。

## 名称与名称下方信息的显示距离可以分别配置

新版为玩家和使用常规生物渲染器的实体新增 `minecraft:nameplate_distance` 与 `minecraft:below_name_distance` 属性，分别控制名称和名称下方信息的显示距离；后者包括设置在名称下方的记分板显示。

旧版两项距离固定为 64 格、10 格；新版默认值保持这两个数值，但可通过属性设置在 0–512 格之间调整。设为 0 可以关闭对应显示，增大数值则可扩展距离。实体仍需在客户端能够接收并渲染的范围内，并通过原有的名称可见性检查；潜行实体原有的 32 格名称限制仍会生效。

## 数据包中的方块状生物大小判断改名

## 自定义地表规则可以按生物群系标签匹配

地表规则中 `minecraft:biome` 条件的 `biome_is` 字段，旧版只接受生物群系 ID 列表；新版可以接受单个 ID、ID 列表或 `#命名空间:标签`。数据包可用同一个标签维护一组采用相同地表材料的生物群系。

已有的有效 ID 列表仍可使用。新版还会将这些 ID 作为注册表引用校验，原先仅因不存在而永不匹配的生物群系 ID，现在会在数据加载时产生错误。

## JFR 报告跳过无法计算分配速率的线程

生成 JFR 性能分析摘要时，如果某线程首末内存分配采样的间隔不足一秒，旧版仍用截断到秒的间隔作除数，可能得到无穷大或非数值；采样时间倒序时也可能得到负速率。新版在首末采样间隔不足一秒或时间倒序时跳过该线程并记录警告，其余线程仍正常统计。这改变了异常采样情况下性能摘要中的线程条目，不改变世界的运行逻辑。
