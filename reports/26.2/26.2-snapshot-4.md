# Minecraft 26.2 Snapshot 4 变更分析

- 上一个版本：`26.2-snapshot-3`
- 当前版本：`26.2-snapshot-4`

## 放置后立即转化的方块会正常扣除物品

本次修改改变了方块放置的成功判定。方块在放入世界后立即变成其他方块，或被用于召唤傀儡时，新版仍将这次放置视为成功，影响湿海绵处理和手动召唤傀儡。

### 差异出现的场景

玩家在生存模式下执行以下操作：

- 在下界放置湿海绵，使它立即变为干海绵。其他具有水蒸发环境属性的位置也适用。
- 将雕刻南瓜或南瓜灯放到已经搭好的对应结构上，成功召唤雪傀儡、铁傀儡或铜傀儡。

### 版本变化

- Snapshot 3：世界中的转化或召唤已经发生，但放置过程因原位置不再是刚放下的方块而返回失败。玩家手中的湿海绵、雕刻南瓜或南瓜灯不会扣除，也不会执行这次手动放置后续的成功结算。
- Snapshot 4：上述情况返回放置成功，正常扣除一个物品，并执行放置声音和放置游戏事件的处理。

### 实际影响

旧版可反复使用同一块湿海绵在下界放出干海绵，也可重复使用同一个南瓜物品手动召唤傀儡；新版这些操作需要消耗对应物品。发射器召唤傀儡原本就会扣除南瓜，不属于此次扣物品差异。

普通 `/setblock` 和 `/fill` 同样会收到新的成功结果。例如在下界放置湿海绵，旧版虽然已经生成干海绵，命令仍可能报告失败；新版将其计入成功设置的方块，影响命令返回值和据此运行的后续命令。`strict` 模式会跳过相关放置回调，不触发这里的转化过程。

## 关闭怪物生成不再拦截常规自然刷怪

常规自然生成不再按“是否允许怪物生成”过滤整个怪物类别。这既让和平难度能够自然生成其中允许在和平难度存在的生物，也使 `spawn_monsters` 规则失去对常规自然刷怪的控制。

### 差异出现的场景

`spawn_mobs` 保持开启，玩家附近存在满足生物自身生成条件、距离条件和生物上限的空间；世界处于和平难度，或将 `spawn_monsters` 设为 `false`。

### 版本变化

- Snapshot 3：和平难度或 `spawn_monsters=false` 会使整个怪物类别跳过常规自然生成。猪灵、疣猪兽、硫方怪虽然能够在和平难度下存活，也不会通过这一流程自然生成。
- Snapshot 4：这层类别过滤被移除。在各自对应的生物群系中，猪灵、疣猪兽和硫方怪能够在和平难度下自然生成。非和平难度下，僵尸、骷髅等也能在 `spawn_monsters=false` 时继续按各自的正常条件自然生成。

生物自己的难度检查仍会执行，因此僵尸等需要非和平难度的生物并不会因此在和平难度生成。`spawn_mobs=false` 仍会关闭这套自然生成流程。幻翼、巡逻队等使用独立生成器的机制仍受原来的怪物生成开关控制，此次变化不能推广到所有生成途径。

### 实际影响

依靠 `spawn_monsters=false` 维持无自然怪物环境的世界，在非和平难度下会重新出现常规自然刷怪。和平难度中的下界生物获取、硫方怪收集和对应生物的自动生产，则新增了自然补充来源。

## 破坏复活仪式的末地水晶会立即中止末影龙复活

末影龙复活仪式会记录参与仪式的末地水晶。新版修正了水晶被破坏时的匹配方式，使破坏任意一颗参与水晶都能立即取消仪式。

### 差异出现的场景

玩家在末地返回传送门周围放置末地水晶并启动末影龙复活，随后在仪式完成前破坏其中一颗参与水晶，且仍有其他参与水晶留存。

### 版本变化

- Snapshot 3：仪式保存的是水晶引用，破坏时却直接用水晶实体查找，无法识别它是否属于仪式。只要仍有参与水晶存在，复活动画、黑曜石柱重建和最终的末影龙复活就可以继续；所有参与水晶都消失时，后续检查才会中止仪式。
- Snapshot 4：按水晶 UUID 匹配仪式记录。破坏任意一颗参与水晶后，立即清除复活阶段和计时，恢复返回传送门，并重置黑曜石柱顶水晶的无敌状态与光束目标。

新版可通过破坏部分参与水晶停止后续黑曜石柱重建；中止前已经重建的黑曜石柱不会回退。

## 自然生成的幼年硫方怪使用小体型

硫方怪自然生成时会初始化年龄和体型。旧版先设置固定的成年体型，新版先确定年龄，再为幼年个体设置小体型。

### 差异出现的场景

自然生成的一批硫方怪中，有个体在年龄初始化时被选为幼年。

### 版本变化

- Snapshot 3：这些幼年硫方怪与成年个体一样大，最大生命值为 8；它们仍按幼年规则接受食物，不能吞入方块，但死亡时会因体型较大而分裂。
- Snapshot 4：这些幼年个体的身体宽高减半，最大生命值为 4，使用小体型的声音，死亡时不再分裂。

改变的是生成时体型与年龄的对应关系，抽到幼年个体的概率没有提高。已经保存的旧个体继续读取原有体型，不会仅因升级并加载世界而自动缩小。

## 硫黄洞穴岩层加入凝灰岩和花岗岩

硫黄洞穴的岩层按噪声值选择材料。新版扩展了材料种类，并调整朱砂和硫黄对应的噪声区间，改变新洞穴中的材料分布。

### 差异出现的场景

在相同种子、相同坐标生成尚未生成过的硫黄洞穴区域。

### 版本变化

- Snapshot 3：岩层只在普通岩石、朱砂和硫黄之间按噪声切换。
- Snapshot 4：过渡区域加入凝灰岩和花岗岩，并重新分配朱砂与硫黄的区间。原先噪声较高处的朱砂区域改为硫黄，部分原有硫黄区域改为朱砂或花岗岩，改变两种材料的采掘位置。

已经生成的洞穴不会重新替换材料；洞穴延伸到新生成区块时，新旧区域可能呈现不同的材料分布。

## 硫黄尖锥簇的随机高度降低

硫黄尖锥簇生成时，先抽取高度参数，再结合洞穴空间和簇内位置决定单根尖锥的长度。新版降低了这个高度参数的取值范围。

### 差异出现的场景

新生成的硫黄洞穴区域中生成硫黄尖锥簇。

### 版本变化

- Snapshot 3：用于生成长度的随机高度参数为 3–6。
- Snapshot 4：该参数降为 1–4，尖锥整体趋于更短。单根尖锥仍受洞穴空间、簇内位置和随机偏差影响，不能将参数范围直接视为每根尖锥的最终长度。

已经生成的尖锥和玩家放置的方块不受影响。

## 缺少 Vulkan 加载器时可以继续尝试 OpenGL

客户端启动时需要加载图形相关本地库，再选择可用的图形后端。新版把 Vulkan 加载器缺失纳入后端回退流程，并在查询设备高级特性前排除仅支持 Vulkan 1.0 的设备。

### 差异出现的场景

系统缺少 Vulkan 加载器，但具有可用的 OpenGL 环境；或 Vulkan 设备仅支持 1.0，需要判定该设备能否用于启动游戏。

### 版本变化

- Snapshot 3：无条件加载 Vulkan 库，缺少加载器时会在本地库初始化阶段直接失败，无法进入后端回退流程。对于仅支持 Vulkan 1.0 的设备，查询高级特性前没有先按版本跳过。
- Snapshot 4：捕获加载器加载失败，跳过依赖它的几个库；选择图形后端时将 Vulkan 判为不可用，继续尝试 OpenGL。在查询高级特性前也会跳过仅支持 Vulkan 1.0 的设备；没有合格设备时，按图形后端创建失败处理，继续尝试 OpenGL。

在 OpenGL 可用的前提下，缺少 Vulkan 加载器的系统因此能够继续启动游戏。

## 名称与名称下方信息的显示距离可以分别配置

新版新增 `minecraft:nameplate_distance` 与 `minecraft:below_name_distance` 属性，分别控制名称和名称下方信息的显示距离。后者包括设置在名称下方的记分板显示。

### 差异出现的场景

为玩家或使用常规生物渲染器的实体设置上述属性，并在客户端查看其名称或名称下方信息。实体需要处于客户端能够接收并渲染的范围内，且通过原有名称可见性检查。

### 版本变化

- Snapshot 3：名称和名称下方信息的距离分别固定为 64 格、10 格，不能通过这两项属性单独调整。
- Snapshot 4：两项属性默认仍为 64 格、10 格，但可分别在 0–512 格之间设置。设为 0 可以关闭对应显示，增大数值则可扩展显示距离；潜行实体原有的 32 格名称限制仍会生效。

## 自定义地表规则可以按生物群系标签匹配

- 数据包使用地表规则的 `minecraft:biome` 条件时，旧版 `biome_is` 只接受生物群系 ID 列表；新版可接受单个 ID、ID 列表或 `#命名空间:标签`，可用标签维护采用相同地表规则的一组生物群系。

## 用桶收放硫方怪增加声音反馈

用桶收起或放出硫方怪时，新版会播放对应的专用声音，并让不含液体的硫方怪桶也执行倒出声音的处理。

### 差异出现的场景

玩家使用桶成功收起硫方怪，或使用硫方怪桶将其放出。

### 版本变化

- Snapshot 3：收起硫方怪时没有专用收取声音；放出时也会跳过倒出声音。
- Snapshot 4：收起和放出时分别触发对应的专用声音；硫方怪桶不含液体也会播放倒出声音。

## JFR 报告跳过无法计算分配速率的线程

- 生成 JFR 性能分析摘要时，若某线程首末内存分配采样的间隔不足一秒，旧版仍以截断到秒的间隔作除数，可能得到无穷大或非数值；采样时间倒序时也可能得到负速率。新版在间隔不足一秒或时间倒序时跳过该线程并记录警告，其余线程正常统计。变化限于异常采样情况下的摘要条目。
