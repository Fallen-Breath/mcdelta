# Minecraft 26.2 Snapshot 7 变更分析

- 上一个版本：`26.2-snapshot-6`
- 当前版本：`26.2-snapshot-7`

## 烈性硫黄新增熔岩驱动的连续喷发

烈性硫黄上方有合适的水柱时，会根据下方热源决定是否喷发。新版在岩浆块驱动的间歇喷发之外，增加熔岩驱动的连续喷发。

### 差异出现的场景

烈性硫黄正上方有水源，向上最多四格的水柱后有可出气的位置，下方为熔岩。

### 版本变化

- Snapshot 6：熔岩不属于涌泉热源，烈性硫黄保持湿润状态，散发会造成反胃的气体。
- Snapshot 7：熔岩使烈性硫黄持续喷发，对进入喷流的实体施加上推力，不进入休眠，也不运行湿润状态的反胃效果。

旧存档中已经处于湿润状态的烈性硫黄，需要重新放置，或由相邻方块变化触发状态检查，才会切入连续喷发。数据包可分别用 `causes_periodic_geyser_eruptions` 和 `causes_continuous_geyser_eruptions` 方块标签指定间歇、连续喷发的热源。

## 烈性硫黄的水柱、喷流与气体改用碰撞形状判断通路

涌泉需要贯通的水柱和出气位置，喷流与反胃气体也会检查遮挡。新版将这些检查改为依据碰撞形状，并让方块整格截断其上方的喷流。

### 差异出现的场景

烈性硫黄上方的水柱、出口或喷流内放有含水台阶、活板门、告示牌等方块；或者玩家眼睛处于无碰撞方块内，并满足反胃气体的其他距离、水源与通路条件。

### 版本变化

- Snapshot 6：水柱检查从上方第二格开始，含水方块只要提供水源就可通过，出口必须是空气。喷流在固定高度内逐个检查实体眼睛与水面之间的视觉遮挡。反胃气体要求眼睛所在格为空气，水面间的遮挡也按视觉形状判断。
- Snapshot 7：水柱从紧贴烈性硫黄的第一格开始检查，具有碰撞形状的含水方块会阻断通路，出口则可以是没有碰撞形状的方块。喷流逐格向上检查，遇到具有碰撞形状的方块后，截断其上方的推力范围。反胃气体允许眼睛处于可通过的无碰撞方块内，水面间改按碰撞形状检查遮挡。

因此，含水台阶或活板门可以堵住原先能通过的水柱，出口处的告示牌等无碰撞方块则不再使涌泉失效。活板门即使打开，只要对应检查得到的碰撞形状非空，仍会截断喷流。没有阻挡时，推力检查的最高范围仍为水柱格数的六倍；创造模式中正在飞行的玩家仍不受上推力。

## 间歇涌泉的基础周期改由种子和坐标决定

岩浆块驱动的间歇涌泉会在休眠与喷发之间循环。新版改变基础时长的取值方式，使同一位置的基础周期保持固定。

### 差异出现的场景

在同一世界、同一坐标拆除并重建间歇涌泉，或升级已经保存了倒计时的涌泉。

### 版本变化

- Snapshot 6：方块实体初始化时随机选取并保存休眠、喷发的基础时长，拆除重建可以重新抽取。
- Snapshot 7：根据世界种子和方块坐标计算基础时长，同一位置重建不再重新抽取。升级时已保存的倒计时先继续运行，进入下一阶段时使用新算法。

基础休眠时长仍为 15～30 秒，基础喷发时长仍为 1～2 秒，随水深增加的附加时长也保留。

## 封顶的甜浆果丛和枯草丛也能接受骨粉

骨粉能催熟甜浆果丛，使矮枯草丛长成高枯草丛，或让高枯草丛向周围扩散。新版移除这些操作对植物正上方空气格的要求。

### 差异出现的场景

玩家或发射器向植物施用骨粉，而植物正上方被占用，或植物已经位于建筑高度顶端。甜浆果丛尚未成熟；高枯草丛周围另有可生成矮枯草丛的位置。

### 版本变化

- Snapshot 6：三种植物都因正上方没有有效的空气格而拒绝骨粉操作。
- Snapshot 7：甜浆果丛可提高一阶段成熟度，矮枯草丛可变为高枯草丛，高枯草丛可向周围扩散。高枯草丛仍是占据一格的植物，生长操作无须占用上方一格。

## 填入圆石等方块的硫方怪不再获得原有液体浮力

硫方怪会根据体内方块获得对应类型的能力。新版移除 `slow_bouncy` 类型提供的液体浮力。

### 差异出现的场景

硫方怪填入圆石、石头、黑曜石等属于 `slow_bouncy` 类型的方块，进入水或熔岩。

### 版本变化

- Snapshot 6：这一类型提供浮力，使硫方怪能够靠该效果上浮。
- Snapshot 7：这一类型不再提供浮力，相同填充物的硫方怪不再靠该效果上浮。若数据包使填充物同时匹配另一种提供浮力的类型，另一类型仍可提供浮力。

## 从桶中放出的空心硫方怪也会保留

硫方怪原本可因体内有方块而避免自然消失。新版将“来自桶”也列为保留条件。

### 差异出现的场景

从桶中放出硫方怪，之后使其失去体内方块，并处于原本会触发普通生物自然消失的条件下。

### 版本变化

- Snapshot 6：失去体内方块后，来自桶的硫方怪仍可能按普通生物规则自然消失。
- Snapshot 7：来自桶的标记继续阻止自然消失，空心状态也会保留。

## 硫方怪的发射器穿戴限制为成年个体的身体槽

硫方怪使用身体槽存放填充物。新版收紧通用装备接口，限制发射器可向它装备的槽位和年龄。

### 差异出现的场景

发射器向空心硫方怪施用普通头盔、胸甲等装备，或通过身体槽装备接口向幼体装备物品。

### 版本变化

- Snapshot 6：硫方怪可接受发射器施加的普通装备，身体槽接口也没有新增的幼体限制。
- Snapshot 7：发射器只允许向成年且存活的硫方怪的身体槽装备物品，还须满足物品允许该实体装备、身体槽为空等条件。普通头部、胸部等装备不再进入硫方怪；身体槽装备接口也会拒绝幼体。

发射器向成年硫方怪填入可吞方块的原有流程仍使用专门的填充判断。

## 监守者能够维持对恶魂的攻击

监守者有自己的攻击目标条件。新版使持续攻击时的检查也使用这套条件，移除通用生物规则对恶魂的额外排除。

### 差异出现的场景

恶魂使监守者积累足够愤怒，成为监守者的攻击目标。

### 版本变化

- Snapshot 6：通用生物攻击检查排除恶魂，监守者不能维持这一攻击目标。
- Snapshot 7：恶魂不再被额外排除，监守者可以维持目标并追击、攻击。队友、创造或旁观玩家、其他监守者等仍受监守者自身的目标条件限制。

## 潜影贝开壳时更新通用高度和眼睛高度

潜影贝开壳会展开实际碰撞箱。新版同时更新通用实体尺寸与眼睛位置，改变依赖这些位置的视角和判断。

### 差异出现的场景

潜影贝从闭壳逐渐开壳，玩家使用以眼睛为锚点的命令、以旁观模式附身潜影贝，或其他机制读取其眼睛位置。

### 版本变化

- Snapshot 6：只更新实际碰撞箱，通用高度和眼睛高度保持闭壳时的值。
- Snapshot 7：通用尺寸与眼睛高度随开壳进度更新。默认大小的潜影贝完全开壳时，通用高度由 1 格增至 2 格，眼睛相对实体位置的高度由 0.5 格增至 1 格，上述命令锚点和旁观视角随之升高。

潜影贝向附着面反方向展开实际碰撞箱的算法，仍由独立的开壳形状计算。

## 玩家纯水平移动不再重复处理上一次竖直碰撞

服务器处理玩家移动时可能保留上一轮的竖直碰撞状态。新版要求本轮确有对应碰撞，才执行碰撞后的速度处理。

### 差异出现的场景

玩家上一轮发生竖直碰撞，接下来的一轮只作水平移动，没有竖直位移，也没有撞到侧面。

### 版本变化

- Snapshot 6：仍可能依据保留的竖直碰撞状态处理速度，再次改写竖直速度，或在弹性方块上重新处理反弹。
- Snapshot 7：本轮不会因旧的竖直碰撞状态而执行该处理。只有本次尝试竖直移动且发生竖直碰撞，或本次发生水平碰撞时，才处理碰撞后的速度。

## 硫黄涌泉结构中的水下尖锥改为含水

## 图集与窗口尺寸上限考虑驱动的单次内存分配限制

新版在计算图像最大边长时，同时考虑驱动的单次内存分配上限，使图集和窗口使用的尺寸上限可能降低。

### 差异出现的场景

使用 Vulkan 时，驱动的单次内存分配上限先于纹理最大边长成为限制，并且图集或窗口需要较大图像。

### 版本变化

- Snapshot 6：按纹理最大边长限制图集与窗口尺寸。
- Snapshot 7：根据图像格式的每像素大小和单次内存分配上限计算可用边长，再与纹理最大边长取较小值。受分配上限约束的设备可用尺寸因此缩小。

## 必要着色器加载失败时先恢复界面着色器

资源重载可能替换必要着色器。新版在重载失败后的处理之前，重新加载原版界面需要的着色器。

### 差异出现的场景

- Snapshot 7：清空缓存后先重新加载原版界面必需着色器，再报告失败，使恢复加载期间的界面仍有可用着色器。
