# Minecraft 26.2-snapshot-6 变更分析

- 上一个版本：`26.2-snapshot-5`
- 当前版本：`26.2-snapshot-6`

## 区块重载后保留同一时刻计划刻的先后次序

同一区块中，多个方块或流体计划刻具有相同的执行时间和优先级时，其先后次序会影响中继器竞争、水流展开等结果。本次修改让存盘保留它们原来的排序依据。

### 差异出现的场景

装置已经排入多个待执行的计划刻，在执行前保存并卸载区块，随后重新加载；其中存在执行时间及优先级相同的计划刻。

### 版本变化

- Snapshot 5：直接按优先队列的内部遍历顺序写盘。这个顺序不保证等同于原先排入的次序，重载时重新分配顺序编号后，同条件计划刻可能换序。
- Snapshot 6：先按原顺序编号排序再写盘，重载后保留同一区块内这些计划刻的相对先后关系。

依赖同刻执行顺序的装置，保存和重载造成的这一种换序因素被消除；这项保留保证限于同一区块内部。

## 发射器优先点燃硫方怪，空点火也会损耗打火石

发射器使用打火石时，目标格内可点燃的硫方怪现在优先于放火、点燃营火和点燃 TNT 方块处理。

### 差异出现的场景

发射器前方一格与吞有 TNT、尚未点燃的硫方怪相交；该格同时允许放置火焰，或存在其他可点燃目标。

### 版本变化

- Snapshot 5：先尝试在目标格放火、点燃营火或蜡烛、点燃 TNT 方块；这些操作均未接管时才尝试点燃硫方怪。
- Snapshot 6：先选择目标格内第一个符合条件的硫方怪并尝试点燃。找到它后，不再执行后面的方块点火分支。

新版还移除了“所有目标均无法点燃”时的失败标记。因此，前方被普通实心方块堵住等没有发生任何点火的情况，旧版不耗耐久并播放失败声，新版仍按成功处理，消耗 1 点打火石耐久并播放正常发射声。目标格存在可爆炸硫方怪但 `tnt_explodes` 已关闭时，点燃尝试同样会被当作成功，并阻止继续尝试其他目标。依靠堵住前方来保护打火石的电路会持续消耗耐久。

## 竖直反弹计入碰撞前运动阶段的空气阻力

实体碰撞后的竖直反弹速度现在会额外计入本刻碰撞前一段运动的阻力，影响黏液块弹射、具有弹性属性的生物及硫方怪运动。

### 差异出现的场景

实体没有抑制反弹，在一刻中先沿竖直方向移动一段距离，再撞到具有有效弹性的地面或其他竖直碰撞面。

### 版本变化

- Snapshot 5：根据碰撞前速度、重力补偿和反弹系数直接得到反弹速度，没有为已经走过的这段路程计入空气阻力。
- Snapshot 6：再乘一个由碰撞前运动比例决定的阻力系数。普通玩家默认空气阻力为 0.98，所以在有碰撞前位移时，反弹后的竖直速度比旧版略低；恰好没有这段位移时不产生该项差异。

硫方怪填充方块后的反弹还会采用它的空气阻力属性，以及落地时脚下方块和自身摩擦修正后的阻力。依靠连续反弹维持高度或周期的装置，其高度和落地时刻可能变化。此次新增的阻力因子只用于竖直反弹。

另有很小的计算精度差异：TNT、下落方块及掉落物的竖直减速，旧版使用双精度的 0.98，新版取得单精度 0.98 换算后的数值；矿车脱轨后的空中减速也从双精度 0.95 改为单精度返回值。差异约在小数点后八位，长时间或精密弹射轨迹比较可能出现很小的坐标偏差。

同一套空气阻力读取还用于出水后的鱿鱼：使用命令改变其 `air_drag_modifier` 时，出水后的竖直速度现在随该属性衰减，旧版固定乘 0.98；默认属性下没有这一差别。

## 硫方怪的击打方向、力度与命中后续处理改变

吞有方块的硫方怪仍免疫相应攻击的生命值伤害，但受到击打后的运动和攻击是否算作成功命中发生了变化。

### 差异出现的场景

玩家或其他实体击打吞有方块的硫方怪，或者用箭等投射物命中它。攻击类型需要属于硫方怪的方块状态免疫范围；普通受击击退还受该伤害类型是否禁止击退限制。

### 版本变化

- Snapshot 5：具有生物攻击者的非爆炸攻击，用攻击者眼睛位置、瞄准位置和硫方怪大小构造一个推力，之后返回“未造成伤害”。其他免疫伤害来源不会通过这一分支施加普通受击击退。
- Snapshot 6：免疫伤害也返回“命中成功”，并在允许击退时调用普通受击击退入口。攻击者存在时，硫方怪用攻击者朝向与双方高低差调整方向，再按吞入方块提供的水平、竖直力度、伤害平方根和击退抗性施加推力；没有攻击者时使用普通实体的击退计算。

新版可以通过瞄准硫方怪的不同高度、从不同高低位置击打来改变水平与竖直推力分配。不同填充方块也有各自的击打力度，旧版以同一个公式处理。

返回成功还会使玩家攻击继续执行成功命中后的流程，例如适用时触发横扫、冲刺或附魔的额外击退，并消耗武器耐久。旧版被上述免疫分支判为未命中的攻击不执行这些成功分支。硫方怪本身依然不因此扣除生命值，反复击打它不再能保持原有武器损耗和运动结果。

## 硫方怪更换多类填充方块的运动特性，岩浆块增加接触伤害

同样的填充方块在新版可能进入另一类运动配置；部分方块也退出了可吞入列表。

- 石头、圆石、深板岩、下界岩、黑石、朱砂、硫黄、石英块、海晶石、紫珀块、混凝土、陶瓦及多数原先归为普通类型的矿石等，改用 `slow_bouncy` 配置。其击退抗性从 0 增至 0.4，反弹系数从 0.5 增至 0.6，空气阻力修正从 0.1 降至 0.05。相同外力更难推动它们，且反弹及空中减速结果改变。
- 铁块、金块、铜块及其对应金属类填充物，击退抗性从 0.7 降至 0.5，反弹系数从 0.2 增至 0.4，摩擦修正从 0.3 增至 0.4。它们更容易被推动、更有弹性，在相同地面上的减速也更明显。
- 海绵、珊瑚块、干海带块、苔藓类方块、南瓜、西瓜等 `fast_flat` 填充物，反弹系数从 0.2 增至 0.5，摩擦修正从 0.1 增至 0.2。其旧版低弹性滑行轨迹会改变。
- 侦测器和红石灯新增为可吞方块，采用 `slow_bouncy` 配置；沙子、红沙、沙砾和红石块不再可吞，手持这些物品交互或把它们丢给成年硫方怪，不再完成原先的填充。
- 岩浆块从普通配置改为 `hot`。旧版吞入岩浆块不会因此烫伤接触者；新版在硫方怪与实体推挤、或玩家接触并推动它时，施加 1 点 `hot_floor` 类型伤害。该接触伤害没有岩浆块踩踏逻辑中的潜行豁免；伤害本身仍可被相应免疫机制阻止。

旧存档中已经吞下沙子、红沙、沙砾或红石块的硫方怪仍保留体内物品，但这四种物品不再匹配任何内置运动配置，因而失去原配置提供的反弹、减摩擦及液体上浮特性；换入其他可吞方块后才会取得相应的新配置。

泥土、草方块、黏土、骨块、煤炭块和混凝土粉末等仍使用普通配置。各类填充物的新水平、竖直击打力度还会叠加到上一条所述的击退算法中，因此不能只按反弹系数预测击打后的完整轨迹。

## 吞有 TNT 的硫方怪改按生物爆炸规则破坏方块

硫方怪吞入 TNT 后的默认威力仍为 3、正常引信仍为 120 刻，但爆炸所属规则和结束处理改变。

### 差异出现的场景

吞有 TNT 的硫方怪被点燃并等到引信归零；世界使用了不同的生物破坏、爆炸掉落规则，或硫方怪带有死亡时生效的状态效果。

### 版本变化

- Snapshot 5：按 TNT 爆炸处理，方块破坏不受 `mob_griefing` 约束，掉落衰减采用 `tnt_explosion_drop_decay`。引信开始后，即使再关闭 `tnt_explodes`，到时仍会爆炸。爆炸前直接移除硫方怪，不按“被杀死”触发状态效果。
- Snapshot 6：按生物爆炸处理。关闭 `mob_griefing` 时保留方块；允许破坏时，掉落衰减改由 `mob_explosion_drop_decay` 控制。引信归零时再次检查 `tnt_explodes`，关闭后只移除硫方怪。结束时会按死亡触发相关状态效果，例如具有对应效果时产生织网或渗浆的死亡结果。

新版爆炸中心还从脚底提升到实体高度的 1/16；硫方怪刚经过传送门、传送冷却尚未结束时，爆炸使用保护下界传送门方块的计算方式。爆炸挖掘装置的破坏范围与掉落结果因此可能变化。

手动点火也遵守禁用规则：关闭 `tnt_explodes` 后，用打火石或火焰弹交互，旧版虽未真正点燃，仍损耗或消耗点火物；新版提示禁用并跳过消耗。已经点燃的硫方怪交互则从直接认定成功改为继续传递交互，使另一只手或物品自身的后续交互有机会执行。

此外，已经点燃的大型硫方怪被强制杀死时不再分裂成幼体。正常吞 TNT 或让成年硫方怪捡起玩家丢下的 TNT，现在还可获得新增进度 `minecraft:husbandry/uh_oh`。

## 烈性硫黄喷涌只托举上方实体，并可被幽匿感测体侦测

## 重载不再延长最近攻击者记忆

生物记住最近攻击自己的生物，并在经过 100 刻后清除这项记录。若受击后经过一段时间再保存、卸载并重载，旧版把“已经过去的时间”加到重载时的年龄上，使攻击时间落在未来；新版改为减去这段时间。

## 硫黄洞穴的分布和岩层构成重做

硫黄洞穴在同一种子中的分布位置发生变化。旧版用于参与生物群系选择的候选范围不限制大陆性和侵蚀度，深度参数为 −1.1～−0.95；新版把大陆性范围收至 −0.19～0.55、侵蚀度收至 0.45～1，并把深度参数扩为 −1.1～−0.85。其选择现在更偏向这些气候参数对应的沿岸、内陆及较高侵蚀度区域。生物群系最终按距离匹配，不能把候选参数边界直接当成绝对禁止生成线。

洞内方块替换也从旧版“默认岩石→凝灰岩→朱砂→花岗岩→硫黄”的噪声渐变，改为三段三维噪声条件：−0.4～−0.1 替换为朱砂，0～0.4 替换为硫黄，大于 0.4 再替换为朱砂；其余噪声范围保留前面生成的岩石。洞穴岩层因此出现新的朱砂、硫黄分区，不再由这条规则生成原来的凝灰岩和花岗岩过渡带。

这些修改作用于新生成区域；旧区块中的生物群系和方块不被本次更新整体重算，同一种子的旧版找洞位置不能直接沿用到新版未生成区域。

## 硫黄涌泉扩大并改为选择较平坦的生成位置

## 管理服务器允许用 0 关闭状态心跳

启用服务器管理协议时，`status-heartbeat-interval=0` 在旧版仍会尝试创建间隔为 0 的定时任务并抛出异常；新版跳过创建任务，可用 0 启动管理服务而不周期性推送状态心跳。运行中把已有的正数间隔设为 0，也会取消现有心跳并返回成功。

不过，本快照取消现有任务后保留了已取消任务的引用。若先开启心跳，再动态设为 0，随后再次动态设置间隔，重复取消会返回失败，新设置不会应用。以 0 启动且尚未创建过心跳任务时，没有这个恢复问题；从已经动态关闭的状态恢复则需要重启管理服务所在的服务器。

## NBT 中由编解码器读取的布尔数值采用非零判断

以物品组件等编解码器读取 NBT 布尔值时，旧版先把数字截为一个字节，再判断是否为零；新版按完整数值是否为零判断。因此，`256`、`0.5f` 这类旧版截断后为零的数值，新版会读成真。

例如，`/give @s stick[enchantment_glint_override=256]` 在旧版把强制附魔光效读成假，新版读成真。常规 `true`、`false` 和 0、1 数据的结果不变。这项变化针对编解码器使用的 NBT 读取入口，不能泛化为所有直接读取 NBT 字节标记的逻辑都改变。

## 结构腐化按前序处理器修改后的方块判断

数据包为结构配置多个处理器，并在后面的 `block_rot` 中设置 `rottable_blocks` 筛选时，旧版根据模板最初的方块种类决定能否腐化；新版根据经过前面处理器修改后的种类判断。

## 旧数据包的硫方怪和根系配置需要迁移

数据包格式从 104 升至 105，以下旧定义不能直接按旧结构沿用：

- 硫方怪类型定义移除 `explosion_fuse`，爆炸改写为包含 `power`、`causes_fire`、`fuse` 的 `explosion` 对象；所有定义还必须提供 `knockback_modifiers` 的水平、竖直力度。继续只写旧引信字段的定义不会获得原来的爆炸能力，缺少新必填字段还会使定义加载失败。
- 根系地物新增必填的 `level_test_distance`、`max_level_deviation`，原先不需要平坦地形检查的配置可填写 0。
- 表面规则删除 `minecraft:noise_gradient` 类型。原有渐变定义需要重写；`noise_threshold` 则新增可选的 `is_3d`，省略时继续使用二维采样。

自定义硫方怪极短引信的异常处理也改变：旧版把引信设为 1～3 刻并由爆炸触发短引信时，会向随机数函数传入 0 上限而抛出异常；新版为随机范围设置至少 1 的上限，短引信得到 0 时也会在下一次实体更新正确进入爆炸结束处理。

硫方怪的身体装备槽现在认可可吞方块，因此 `/item replace entity … armor.body with …` 可以直接把这类方块放入硫方怪体内，旧版槽位校验会拒绝普通可吞方块。

## Vulkan 渲染新增设备能力要求

选择 Vulkan 后端时，新版要求显卡驱动提供 `VK_EXT_vertex_attribute_divisor` 扩展及 `vertexAttributeInstanceRateDivisor` 功能。旧版没有这两项要求；仅缺少这些能力、原先还能使用 Vulkan 的设备，现在会在选择或创建设备时被拒绝，并进入后端创建失败处理。这项限制针对 Vulkan 后端，不代表同一设备的 OpenGL 后端也被同样条件排除。

OpenGL 的区块上传还增加了持久映射能力检查：需要绕过慢速写入、但又不支持持久映射的设备，新版使用 CPU 暂存上传路径；旧版会选择一直保持映射的上传缓冲区。

## 暗处雾色和信标光束的雾效变化

夜视效果或水下视野增强正在提亮雾色时，如果原始雾很暗、最亮通道低于 0.07，新版只让最亮通道继续按原来的最大幅度提亮，其余颜色通道的放大受限；旧版把全部通道按相同比例放大。因此，这些有色暗雾会更突出主色。主世界的夜间雾色也从旧版一段固定偏蓝的色调，改为从前半夜偏蓝逐渐过渡到后半夜较中性的灰色。

信标光束改为直接使用片元的透视深度计算雾效。旧公式假定一套固定的深度映射，在 Vulkan 或启用零到一深度的 OpenGL 设备上可能算错距离；新版不再依赖这套深度区间假设，光束随距离进入雾中的表现随之修正。
