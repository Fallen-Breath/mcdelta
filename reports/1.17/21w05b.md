# Minecraft 21w05b 变更分析

- 上一个版本：21w05a
- 当前版本：21w05b

## 负坐标处生物变大时，碰撞检查不再延伸到原点附近

生物体型变大时，服务端会检查附近方块，尝试找到能够容纳新体型的位置。新版修正了这项检查在负坐标处搜索范围异常扩大的问题。

### 差异出现的场景

已经开始正常运行的非玩家实体体型变大，例如幼年动物长大，或河豚从收缩状态开始膨胀。实体位于负 X 或负 Z 区域，且用于寻找位置的小范围整体落在该轴的负半轴。

### 版本变化

- 21w05a：计算检查范围时，把各轴上界的初始值设成了一个极小的正数。负半轴内的实际坐标无法替换这个上界，因此检查范围会沿相关轴一直延伸到 0 附近。离原点越远，需要遍历的方块位置越多；X、Z 同时为较大的负数时，范围还会同时在两个方向扩大，可能造成严重卡顿或长时间无响应。
- 21w05b：直接使用候选位置范围的实际边界，只检查生物附近的方块，消除上述随负坐标距离增加的额外开销。

负坐标处的动物养殖场、村民繁殖设施和利用河豚膨胀的装置都可能受益。触发条件是实体体型增大；这条检查路径排除了玩家，也跳过实体的第一个 tick，因此不能把影响扩大到所有负坐标移动或玩家姿态切换。

## 从更早快照升级时，铜建筑和物品能够保留原来的氧化阶段

21w05a 调整铜系列的氧化阶段命名后，没有配套转换更早存档中的旧名称。21w05b 补上了方块和物品转换，影响直接升级旧世界时铜建筑和库存的保留情况。

### 差异出现的场景

加载仍按 21w05a 之前格式保存的数据，其中存有使用 `lightly_weathered_*`、`semi_weathered_*` 等旧名称的铜方块、对应物品，或者旧名称下已经完全氧化的 `weathered_*` 铜方块。转换也涵盖切制铜块、楼梯、台阶及已有的相应涂蜡变种。

### 版本变化

- 21w05a：没有把上述旧名称转换成新名称。已经不再注册的方块名称读取为空气，对应物品读成空物品堆；仍然存在的 `weathered_*` 名称则被解释为新版的中间氧化阶段，使原来已经完全氧化的铜发生阶段变化。
- 21w05b：升级时先将 `lightly_weathered_*` 转成 `exposed_*`、`semi_weathered_*` 转成 `weathered_*`，并将旧版表示完全氧化的 `weathered_*` 转成 `oxidized_*`；随后再应用本次完整铜方块 ID 的调整。原有铜建筑、库存和对应结构数据能够保留原来的氧化阶段，而不是消失或变回中间阶段。

转换按数据原本保存的版本执行。在 21w05a 正常保存的 `weathered_*` 数据会保留其在 21w05a 中的含义；拼图方块中记录的最终方块状态也在转换范围内。已经在 21w05a 中被读取为空气、空物品堆并重新保存的数据，无法靠这次名称转换恢复。

## 完整铜方块的 ID 调整，并同步改变相关配方 ID

直接从 21w05a 升级时，以下方块和对应物品使用新 ID。表中均省略 `minecraft:` 前缀。

| 21w05a | 21w05b |
| --- | --- |
| `exposed_copper_block` | `exposed_copper` |
| `weathered_copper_block` | `weathered_copper` |
| `oxidized_copper_block` | `oxidized_copper` |
| `waxed_copper` | `waxed_copper_block` |

存档中的方块和物品会自动转换。原来直接使用旧 ID 的 `/give`、`/setblock` 等命令，以及数据包中的物品、方块引用，需要改为新 ID；命令文本和数据包文件本身不在上述存档转换范围内。

相关加工配方使用了新的材料 ID，产物数量和加工方式保持原状。以下配方的 ID 也随之改变：

- 涂蜡铜块配方从 `waxed_copper` 改为 `waxed_copper_block`。
- 由三种氧化阶段的完整铜方块切石得到切制铜块、楼梯和台阶的配方，ID 中的 `_from_exposed_copper_block_`、`_from_weathered_copper_block_`、`_from_oxidized_copper_block_` 分别去掉 `copper` 后的 `_block`。
- 由涂蜡铜块切石得到切制铜块、楼梯和台阶的配方，ID 中的 `_from_waxed_copper_` 改为 `_from_waxed_copper_block_`。

引用这些旧配方 ID 的命令和数据包也要同步调整。玩家配方本中以被替换的旧 ID 保存的解锁记录，在新版读取时会因找不到配方而被丢弃，不能自动迁移为新 ID 的解锁记录。
