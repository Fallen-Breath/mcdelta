# Minecraft 25w36a 变更分析

- 上一个版本：25w35a
- 当前版本：25w36a

## 加载其他玩家实体会触发客户端渲染异常

新版玩家渲染器重构遗漏了其他联机玩家，影响普通多人游戏和局域网联机。

### 差异出现的场景

客户端已经接收到另一名玩家的实体，并开始遍历世界中的实体以判断是否渲染。另一名玩家不必实际出现在画面中央；异常发生在视锥和距离判断之前。

### 版本变化

- 25w35a：本地玩家和其他玩家都通过客户端玩家公共类型选择玩家渲染器，能够正常显示。
- 25w36a：只有本地玩家和 mannequin 走专门的渲染器分支。其他玩家仍被创建为 `RemotePlayer`，却转去查询没有注册玩家类型的普通实体渲染器表，取得空值；随后的渲染判断直接调用这个空值，导致客户端崩溃。

这是源码调用链直接显示的异常路径，影响加载到其他玩家实体的客户端；独自进入单人世界不会因这条路径触发异常。

## 末影箱进入渲染范围会导致客户端崩溃

25w35a 的箱子渲染器会先检查方块是否具有单箱、左半箱、右半箱的类型属性；末影箱没有这个属性，因此按单箱处理，可以正常显示。

25w36a 在计算开合和光照数据时又无条件读取该属性。末影箱仍使用这一渲染器，却只有朝向和含水状态，因此只要放置在世界中的末影箱进入方块实体渲染范围，就会因读取不存在的属性抛出异常，导致客户端崩溃。这里涉及的是世界内放置的末影箱，物品栏中的末影箱物品使用另一套特殊模型渲染流程。

## 世界边界按维度独立，并改变旧世界迁移与缩放保存行为

世界边界现在存入各维度的 `data/world_border.dat`。原先在任意维度执行命令都修改主世界边界，并向其他维度同步；新版直接操作命令执行所在维度的边界。

### 差异出现的场景

在下界、末地或自定义维度运行 `/worldborder`，从旧版世界首次升级，或者让边界在较长时间内持续缩放后保存并重启。

### 版本变化

- 25w35a：中心、大小、伤害和警告设置由主世界统一控制；下界等带坐标缩放的维度使用换算后的中心。边界变化包广播给所有维度的玩家，边界设置随世界信息保存。
- 25w36a：各维度独立保存、修改和发送边界信息，进入维度时也读取该维度的边界。在下界执行 `/worldborder set 100` 只改变下界；需要同步多个维度的地图命令必须分别执行。

旧设置迁移时仍按维度坐标比例换算中心，大小和其他参数原样复制。不过，专用服务器的普通启动流程会在迁移前读取主世界出生点，进而提前创建默认主世界边界。迁移代码发现边界已经存在便跳过主世界，因此首次升级时，旧主世界的非默认边界会丢失并恢复默认设置；尚未提前创建边界的其他维度仍继承旧设置。单人世界若从 `level.dat` 读到完整的玩家所在维度和位置，会绕过这次出生点查询，可以正常迁移主世界边界。

持续缩放另有保存差异：旧版每次保存都会记录当时的大小与剩余时间；新版只在开始设置和缩放结束时将边界标记为需要保存。若缩放中途已经保存一次，此后既未结束、也未再修改边界设置，那么再次保存和停服保存不会刷新缩放进度；重启后会从较早一次写盘时的大小与剩余时间继续，而非停服时的进度。

## 雷击避雷针改为清除避雷针自身的氧化

雷击命中避雷针时，清除铜方块氧化的起点发生变化。

- 25w35a：先沿避雷针朝向的反方向找到其连接的方块。如果该方块是未涂蜡的铜方块，就将其完全还原，再从该方块向周围随机清除氧化；避雷针自身不因此还原。
- 25w36a：直接检查被雷击的方块。未涂蜡的避雷针自身完全还原，周围随机清除也从避雷针位置开始；其连接的铜块只可能被随机过程逐级还原，不再保证完全还原。雷击涂蜡避雷针时，避雷针不是可氧化铜方块，整段清除过程不启动，即使其连接着未涂蜡铜块也如此。

利用避雷针稳定还原背后铜块的布置会改变结果；把未涂蜡避雷针装在普通方块上，也可以从避雷针处启动周围铜块的随机还原。

## 唤魔者在和平难度下会消失

25w35a 的唤魔者没有被标记为不能在和平难度存留，因此切换到和平后仍会留下。25w36a 增加这一标记，已加载的唤魔者会被移除；命名或设置持久化也不能阻止这项和平难度检查。已有唤魔者收藏和装置会因此失去实体。

## 铜傀儡选择箱子与大箱子比较器更新调整

- 选择新的搬运目标时，25w35a 会把设有容器锁的箱子纳入候选；25w36a 跳过被选中方块实体自身带锁的箱子。检查发生在选取新目标时，因此并非对已选定目标的每次存取都重新验证锁，也不等于检查大箱子另一半的锁。
- 搜索距离排序从铜傀儡所在方块的整数坐标改为它的实际位置。几个箱子非常接近时，同一站位下首先访问的箱子可能改变；旧版排序偏向所在方块较小坐标的一侧。
- 每次取放后，新版额外通知整个容器发生变化。单箱原来的取放操作已经会更新自身；大箱子原来只通知实际变动物品的那一半，新版会通知两半。因此，读取另一半的大箱子比较器也会更新，避免该侧信号保持旧值。

## 不同朝向的展示架不再干扰通电连接

当一个展示架通电，它左右邻接着已经通电但朝向不同的展示架时，25w35a 会把那个邻居自身所在的连接组也计入长度，却无法真正修改不同朝向邻居的连接状态。这会让当前展示架出现单向连接，或者因误算三架上限而漏连另一侧本来可连接的展示架。

25w36a 先检查邻居是否与当前展示架朝向一致；不一致时按没有可连接邻居处理。转角处的展示架组合因此不再影响同向一排展示架的连接状态和快捷栏交换组。

## 铜傀儡像保留姿态和名称，蜜脾可以正常涂蜡

- 25w35a 挖下铜傀儡像时只掉落普通物品，名称和姿态丢失；普通选取方块也不会复制这些信息。25w36a 的掉落物保留自定义名称和姿态，选取方块也会复制它们，重新放置后可还原展示效果。此变化适用于所有氧化与涂蜡状态；不同名称或姿态的像不能再作为相同组件的物品堆叠。
- 对未涂蜡铜傀儡像使用蜜脾，25w35a 被方块的换姿态操作抢先处理，只改变姿态而无法涂蜡。25w36a 会让蜜脾继续执行物品的涂蜡操作，不再先切换姿态。

## 画可以与不同朝向的物品展示框重叠

在各自支撑方块和方块碰撞均允许、但实体边界框相交的情况下，25w35a 的画不能与任何物品展示框重叠；物品展示框也不能与画重叠。

25w36a 允许画和朝向不同的物品展示框或荧光物品展示框共存，放置先后顺序不再影响这一结果。同向的画与展示框仍冲突；两幅画属于同一种实体类型，仍不能相互重叠。

## 世界出生点搜索不再把水和熔岩当作空位

世界出生点需要修正高度时，例如冒险模式的出生流程或普通出生候选全部失败后的回退，25w35a 的碰撞检查虽然要求排除流体，却因为没有待出生实体而使用了忽略流体的上下文。因此，搜索可能向下落到水或熔岩内部。

25w36a 为这种检查加入包含流体的空上下文：普通水和熔岩方块被视为占据完整方块，搜索会继续向上找到能容纳玩家的位置。普通出生候选的身体碰撞检查也采用同一修正。这不是床或重生锚周围落点算法的改写。

## 异常低气泡值也会触发溺水或脱水伤害

25w35a 仅在空气值恰好减到 `-20` 时造成伤害；用命令或自定义数据把空气值设得更低后，后续继续减少反而会跳过伤害。25w36a 改为小于或等于 `-20` 即触发，并把空气值重置为 0，因此不能再用过低的 `Air` 值绕过此机制。

## 同一个按键可以同时驱动多个绑定

## macOS 关闭界面不再错误恢复“按住”模式的潜行等操作

在 macOS 上，潜行、疾跑、使用和攻击的键盘绑定采用按住模式时，25w35a 在打开界面前记录这些绑定是否按下，却不检查其是否启用切换模式；关闭界面时会错误恢复成按下状态，即使玩家已在界面里松开实体按键。Windows 和 Linux 通常会在重新抓取鼠标时读取实际键盘状态，从而覆盖这个错误状态。

## 网络包处理不再插入同步等待区块的过程中

25w35a 将收到的主线程网络包放入普通服务器任务队列。某项操作同步等待区块加载并继续执行任务队列时，还可以处理期间收到的其他移动、交互等网络包。

25w36a 使用独立网络包队列，在服务器进入两刻之间的等待阶段前集中处理。同步等待区块加载的普通任务循环不会排空这个队列，因此期间到达的网络操作会等当前操作结束、回到网络包处理点后再执行，减少玩家操作在未完成的区块相关流程中途交错的情况。客户端也改为在每帧普通任务和游戏刻之前集中处理网络包。

## 无原因的封禁会影响命令反馈

25w35a 在 `/ban`、`/ban-ip` 或管理接口没有提供原因时，自动存入默认原因字符串。25w36a 保留“未提供原因”的状态；管理接口返回的原因字段可以缺省，被封禁玩家再次登录时会获得默认原因消息。

## 命令和自定义数据的边界处理

- 在世界高度范围之外运行 `/locate structure`、`/locate biome` 或 `/locate poi`，25w35a 直接使用执行位置的高度；25w36a 先将搜索起点高度限制到该维度的有效高度范围。高空或虚空中的搜索，尤其包含垂直距离的生物群系搜索，会从有效高度开始，可能得到不同目标与距离。
- `/spectate` 在 25w35a 允许选择 `marker` 这类客户端追踪距离为 0 的实体，客户端实际上收不到对应实体；25w36a 直接拒绝把它设为观察目标并返回错误。
- JSON 中整数或实数范围的最小值大于最大值时，例如谓词范围 `{"min":5,"max":1}`，25w35a 接受该范围但通常永远不能匹配；25w36a 在读取时报告范围颠倒错误。此校验不用于需要跨越正负角度边界的旋转范围。
- 自定义 `root_system` 特性的 `hanging_roots_vertical_span` 在 25w35a 可设为 0，但实际执行垂根生成尝试时会调用上界为 0 的随机数并抛出异常；25w36a 在读取配置时要求为 1～16，提前拒绝这种配置。

## 旧格式物品升级会过滤无效名称、描述和非正附魔等级

从仍使用 `tag.display.Name`、`tag.display.Lore` 和旧附魔列表的物品数据升级时，25w35a 直接把这些名称和描述送入组件转换；25w36a 只保留严格合法 JSON 的名称与描述行。包含未加引号文字、单引号等宽松 JSON 写法的旧自定义名称会被丢弃，描述中的相应行会被删除，即使后续宽松文本转换原本有机会接受它们。

旧附魔列表中等级小于或等于 0 的条目，25w35a 会继续写入附魔组件转换结果；25w36a 在构建组件前将它们过滤。上述差异只作用于需要经过旧物品格式转换的世界或物品数据，不会重新清理已经采用组件格式的 25w35a 物品。

## 文本输入和界面键盘操作调整

- 单行输入框在 25w35a 中双击只会移动光标；25w36a 双击会选中所点位置附近的单词，适用于聊天、搜索和重命名等单行文本框。
- 输入基本多文种平面之外的字符时，25w35a 将其拆成两个 UTF-16 代理字符分别插入，单行输入框只剩一个字符单位容量时可能留下半个字符；25w36a 一次插入完整码点，在这种容量不足场景下整体拒绝，不再留下半个字符。
- 资源包或数据包选择列表原先可以用空格或主键盘回车执行选中项操作；25w36a 改为主键盘回车或数字键盘回车，空格不再执行。
- 创建世界等使用页签导航栏的界面，25w36a 新增 `Ctrl+0` 选择最后一个页签；macOS 使用对应的 Command 组合。25w35a 没有这个快捷键。
- 具有切换游戏模式权限时，在播放终末之诗或制作人员名单期间，25w35a 的 `F3+F4` 能把界面替换为游戏模式切换器；25w36a 在这些页面不再打开切换器，避免跳出结尾播放流程。

## 粒子显示上限和命令参数调整

25w35a 的方块碎屑、不透明普通粒子、半透明普通粒子分别拥有 16,384 个粒子的保留队列；25w36a 将这些四边形粒子合并为同一个 16,384 个的队列。大量混合粒子同时存在时，现在会相互挤掉较早生成的粒子，更早消失；大量挖掘碎屑也可能挤掉其他普通粒子。粒子还增加了扩大后视锥的位置筛选，处于筛选范围之外的粒子不再提交绘制。

命令和自定义数据方面，`dragon_breath` 新增可选 `power`，`effect`、`instant_effect` 新增可选 `color` 和 `power`，其中 `power` 默认 1；`flash` 从无参数粒子改为要求 `color` 参数，原有仅写粒子名的命令或自定义粒子数据需要补上颜色。原版末影龙和药水的调用也使用这些参数传递效果。光灵箭飞行轨迹原先使用 `instant_effect` 粒子，新版改用白色的 `effect` 粒子，轨迹动画随之改变。

## 展示架中的物品对齐高度改变

- 通过方块数据将展示架的 `align_items_to_bottom` 设为 `true` 时，25w35a 的底对齐基准为方块中心下方 1/8 格；25w36a 改为下方 1/4 格。因此在模型边界计算相同的情况下，物品整体比旧版下移 1/8 格。默认的居中对齐不使用这项额外位移。
- 箱子、潜影盒、旗帜等特殊物品模型另受边界计算回归影响：25w35a 用各顶点的独立坐标收集完整轮廓，25w36a 在每个立方体内反复修改并保存同一坐标对象，使收集结果只剩该立方体最后访问的顶点。展示架根据这些残缺边界进行居中或底部对齐，特殊物品因而可能偏离实际模型的中心或底部，具体偏移取决于物品模型与姿态。

## 旁观模式不再显示结构和测试区域边界
