# Minecraft 26.4 Snapshot 6 变更分析

- 上一个版本：`26.4-snapshot-5`
- 当前版本：`26.4-snapshot-6`

## 高速穿水的落地伤害按完整运动路径处理

坠落结算移到沿途方块与流体接触处理之后，使同一次运动中途接触的水能够参与落地判定。

### 差异出现的场景

实体在一次移动中穿过薄水层，随后落到水外的地面，尤其是水位于起点八格以外，或只有实体身体边缘擦过水层的情况。

### 版本变化

- Snapshot 5：移动前用于重置坠落距离的射线沿实体位置中心检查，最多检查前八格；移动后的入水检查还可能发现终点的水，但不能补齐所有中途穿水的情况。上述水层可能被漏掉，实体仍按此前的坠落距离受伤。
- Snapshot 6：先检查实体身体沿运动路径与水的接触，再累计本次下降距离并应用流体的坠落距离倍率。即使终点已经离开水，只要该次运动确实接触水，结算用的坠落距离也会归零。

代码出处：[Snapshot 5：旧版八格射线](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/world/entity/Entity.java#L764)；[Snapshot 6：接触处理后的坠落结算](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/Entity.java#L959)；[Snapshot 6：沿途接触水的倍率](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/EntityFluidInteraction.java#L264)；[Snapshot 6：玩家沿途检查和传送门条件](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/server/level/ServerPlayer.java#L401)。

## 沿途经过攀爬方块和特定传送门会重置坠落距离

梯子、藤蔓、脚手架、蜘蛛网及甜浆果丛等方块的坠落距离重置，改由沿途方块接触处理触发；玩家还增加了特定传送门的重置条件。

### 差异出现的场景

实体已有坠落距离，随后在一次移动中经过重置坠落距离的方块；这类方块仍要求实体位置中心的轨迹经过其内部检测范围。另包括玩家触碰末地传送门、末地折跃门，或传送等待时间设为零的下界传送门。

### 版本变化

- Snapshot 5：移动前的重置射线要求单次位移至少一格，且最多检查前八格；不满足这些条件时，不能靠这条射线重置。玩家接触上述传送门时也没有这项专门的重置处理。
- Snapshot 6：沿途方块接触处理不再受这条射线的最小位移和八格截断限制，经过相应检测范围时会清除已累计的坠落距离。玩家接触上述传送门时，也会清除已累计的坠落距离。

代码出处：[Snapshot 5：旧版重置射线](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/world/entity/Entity.java#L764)；[Snapshot 5：旧版玩家方块接触](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/server/level/ServerPlayer.java#L573)；[Snapshot 6：方块接触时重置](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/Entity.java#L1430)；[Snapshot 6：玩家沿途检查和传送门条件](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/server/level/ServerPlayer.java#L401)；[Snapshot 6：玩家接触传送门](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/server/level/ServerPlayer.java#L620)。

## 同一刻的多段移动合并结算坠落距离

服务器自行模拟运动的实体，改为在处理完本刻的沿途接触后合并计算坠落距离。

### 差异出现的场景

同一实体在同一刻内发生多段移动，尤其是先下降、再上升的情况。玩家移动包仍使用专门的结算路径。

### 版本变化

- Snapshot 5：每次移动分别结算坠落；每一段下降都可以增加坠落距离，即使同刻还有上升。
- Snapshot 6：先合计各段竖直位移，再根据合计下降量累计坠落距离，并按此时是否着地结算。先下降再上升时，上升部分会抵消本刻的下降量。

代码出处：[Snapshot 5：每次移动时结算](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/world/entity/Entity.java#L797)；[Snapshot 6：合计竖直位移后结算](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/Entity.java#L959)。

## 熔岩减免包含本次新增的坠落距离

熔岩对坠落距离的减半处理移到本次下降距离累计之后。

### 差异出现的场景

实体持续接触熔岩并向下移动；比较时已有坠落距离和本次下降距离相同。

### 版本变化

- Snapshot 5：先把已有坠落距离减半，再加本次下降距离。
- Snapshot 6：先加本次下降距离，再整体减半；本次新增的下降距离也受到减免。

代码出处：[Snapshot 5：旧版熔岩减半处理](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/world/entity/Entity.java#L565)；[Snapshot 6：先累计再应用流体倍率](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/Entity.java#L1590)；[Snapshot 6：流体倍率选择](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/world/entity/EntityFluidInteraction.java#L264)。

## 脆冰踩裂遵守出生点保护和生物破坏规则

脆冰的直接踩裂增加权限检查，同时调整流浪者和潜影贝触发踩裂的方式。

### 差异出现的场景

玩家或生物站在脆冰上，服务器启用了出生点保护或将 `mobGriefing` 设为 `false`；另包括流浪者和附着在脆冰上方的潜影贝。

### 版本变化

- Snapshot 5：除冻尸等标签排除对象外，踩裂条件不检查出生点保护或 `mobGriefing`，流浪者也会踩裂。潜影贝没有主动执行脚下脆冰踩踏检查的处理。
- Snapshot 6：玩家只有在不受该位置的出生点保护限制时才会直接踩裂；非玩家生物只有在 `mobGriefing=true` 时才会直接踩裂。流浪者获得豁免；潜影贝附着在脆冰上方时会主动执行踩踏检查，符合破坏条件便会使其开裂。

出生点保护检查针对踩踏的玩家，生物仍按生物破坏规则处理。上述权限检查也不会阻止相邻脆冰破裂引起的裂纹传播。

## 村民召唤铁傀儡不再选用脆冰地面

村民召唤铁傀儡时使用的地面检查新增脆冰排除条件。

### 差异出现的场景

村民尝试召唤铁傀儡，候选生成位置下方是脆冰，且其余生成条件满足要求。

### 版本变化

- Snapshot 5：脆冰可通过这项地面检查，能够作为刷铁平台的生成地面。
- Snapshot 6：脆冰被地面检查拒绝，该位置不能用于这次召唤。

### 差异出现的场景

## 浮冰砖系列需要用镐采集

浮冰砖增加正确工具要求，并由其派生的台阶、楼梯、墙和雕纹浮冰继承。

### 差异出现的场景

采掘浮冰砖、浮冰砖台阶、浮冰砖楼梯、浮冰砖墙或雕纹浮冰。

### 版本变化

- Snapshot 5：用手或其他不合适的工具破坏也能获得方块。
- Snapshot 6：必须使用合适的镐才会掉落物品，不要求精准采集；使用不合适的工具仍可破坏方块，但不会获得掉落物。

## 唱片机轮播减少换片振动并改变出片位置

唱片机轮播模式下，唱片槽变化的游戏事件和弹出唱片的位置一同调整。

### 差异出现的场景

唱片机上方紧贴用于轮播的单箱容器：普通箱子、陷阱箱或任意状态的铜箱。比较轮播换片、重播，以及玩家弹出唱片的结果。

### 版本变化

- Snapshot 5：轮播换片或重播时，设置唱片仍会发出“方块改变”游戏事件，产生额外的频率 11 振动。弹出的唱片出现在唱片机上表面附近，水平位置随机偏移，可能落在上方箱子内部。
- Snapshot 6：轮播模式下跳过唱片槽变化产生的“方块改变”事件，因此幽匿感测体不再从该动作获得额外的频率 11 振动。弹出的唱片改在唱片机底面上方约 2.2 格、水平中心处生成，即箱子顶面以上。

事件抑制也适用于轮播模式下人工或漏斗造成的唱片槽变化。依靠原出片位置收集唱片的装置，会遇到不同的物品落点。

## 蓝冰硫方怪能够浮水和冻结附近水面

硫方怪吞入蓝冰后，新增浮力及冻结附近水面的冷属性效果。

### 差异出现的场景

硫方怪体内装有蓝冰，在水边着地且没有乘坐其他实体。待冻结的水位于脚下那一层、水平距离三格以内，水上方为空气，待放置冰块的位置没有实体阻挡。

### 版本变化

- Snapshot 5：蓝冰提供快速滑动属性，不会冻结水，也没有由蓝冰提供的液体浮力。
- Snapshot 6：蓝冰改为冷属性，保留原有滑动、弹性和击退属性，同时获得浮力。在跨入不同方块位置、着地或刚获得此属性等触发时，将符合条件的水替换成霜冰；满足条件的流水也能冻结。

冻结不检查 `mobGriefing`，关闭生物破坏规则后仍可发生。生成的霜冰会按其老化规则融化；硫方怪在空中或作为乘客时不触发冻结。

## 新生成的村民交易调整蛋糕价格和铁剑库存

村民生成新报价时，农民的蛋糕基础价格和武器匠的铁剑使用上限采用新参数。

## 提前结束挖掘时，服务器正确继续累计进度

客户端提前报告挖掘完成后，服务器延后完成分支改用实际经过的刻数累计进度。

### 差异出现的场景

客户端发出“挖掘完成”，但服务器计算的进度仍低于 70%，因而进入延后完成处理。高延迟或两端挖掘速度判断不一致时更容易遇到。

### 版本变化

- Snapshot 5：后续每刻把开始挖掘时的服务器计数错当成已挖掘时长，可能使方块立即破坏，或让进度停滞。
- Snapshot 6：使用从开始挖掘至当前实际经过的刻数，方块按累计进度完成破坏。

## 超大文本展开增加片段数和纯文本长度上限

通用文本处理增加限制，超过上限的后续内容不再进入相应处理路径。

### 差异出现的场景

命令、数据包或服务器生成包含大量子片段或极长内容的文本，并用于聊天排版、宽度测量或依赖纯文本的名称判断。

### 版本变化

- Snapshot 5：通用文本遍历没有片段数限制，默认完整纯文本转换也没有统一长度上限。
- Snapshot 6：常用遍历路径最多处理 65,536 个片段，默认完整纯文本转换最多保留 1,048,576 个 Java 字符单位。超出部分不再由这些路径处理，相关显示或名称判断可能只使用前面的内容。

正常长度的文本不会触及这些限制。

代码出处：[Snapshot 5：旧版无统一遍历上限](https://github.com/TISUnion/guardian/blob/9a2b8420960f505357c344d14ef2ae7eb8444563/src/main/java/net/minecraft/network/chat/FormattedText.java#L12)；[Snapshot 6：片段数上限](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/network/chat/FormattedText.java#L10)；[Snapshot 6：默认纯文本长度](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/network/chat/Component.java#L29)；[Snapshot 6：换行片段处理](https://github.com/TISUnion/guardian/blob/143e01f3079a4e891e0c74dc7199d830ce202fce/src/main/java/net/minecraft/client/StringSplitter.java#L245)。
