# Minecraft 26.1 变更分析

- 上一个版本：`26.1-rc-3`
- 当前版本：`26.1`

本次正式版没有修改方块、物品、实体、地形生成或装置运行规则；可观察差异主要来自正式版身份及版本号切换。

## 正式版与 RC 3 不能直接混用联机

26.1-rc-3 客户端可以连接同版本服务端，26.1 客户端可以连接 26.1 服务端。将其中一端单独升级到 26.1 后，原版服务端会在登录握手时拒绝另一端，提示版本不兼容。协议号从 `1073742127` 改为 `775`，因此现有 RC 3 服务器升级时，玩家客户端也需要同步切换。

## Realms 切回正式版服务流程

在正常的 Realms 服务环境中打开服务器列表，26.1-rc-3 使用预发布版本模式；26.1 使用正式版模式，请求的世界列表和发给服务端的预发布标志随之改变。原先在 RC 3 中使用的测试 Realm 入口，不会在正式版中继续按预发布模式列出。加入世界时，26.1 也不再经过预发布模式专用的升级、降级及兼容性确认分支；能否实际加入仍取决于 Realms 返回的服务器状态和版本。

## 打开旧世界时不再触发“升级到快照”备份询问

对于与当前版本兼容、不需要文件结构迁移，且数据版本低于 RC 3 的同一个世界：

- 26.1-rc-3：打开时会询问是否先备份，因为当前客户端属于预发布版本。
- 26.1：不再仅因世界版本较旧而显示这项询问，继续加载世界。

世界数据版本同时从 `4785` 增加到 `4786`。经 26.1 保存的世界如果再用 RC 3 打开，会进入旧客户端已有的降级备份警告流程。本次没有新增数据转换规则。

## 创建世界界面的实验入口调整

26.1-rc-3 在创建世界的“游戏”页中额外显示“实验”按钮；26.1 隐藏这处入口。“更多”页中的“实验”按钮仍然可用，已有实验功能的配置能力没有因此取消。
