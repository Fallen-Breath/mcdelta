# Minecraft 26.1-snapshot-3 变更分析

- 上一个版本：`26.1-snapshot-2`
- 当前版本：`26.1-snapshot-3`

## 南瓜和西瓜改为只能在耕地上结出

成熟瓜茎选择结果位置时，新版收窄了果实下方允许的方块，直接影响使用泥土、草方块等作为结果面的农场。

### 差异出现的场景

成熟南瓜茎或西瓜茎旁边留有空气，空气下方是泥土、草方块、砂土、灰化土等原本属于 `minecraft:dirt` 标签的方块。

### 版本变化

- Snapshot 2：果实下方是耕地或上述泥土类方块时，可以结出果实。
- Snapshot 3：果实下方必须属于 `minecraft:grows_crops`；原版数据中该标签只有耕地。原有泥土类结果面不能再产生新的南瓜或西瓜。

已有果实不会因此消失。使用普通泥土结果面的自动农场，在收走已有果实后停止补充；瓜茎本身能够继续生长，并不表示结果面仍然有效。

## 气泡柱能够替换含水方块，拆除底座也不再使整列消退

气泡柱的延伸检查改为读取方块中的流体，同时改变了失去底座后的处理。

### 差异出现的场景

气泡柱上方有含完整静止水源的方块，例如含水台阶、含水栅栏，或海带；或者拆除已经形成气泡柱的灵魂沙、岩浆块底座。

### 版本变化

- Snapshot 2：气泡柱只能继续替换独立水源方块，遇到含水方块会停止。拆除底座后，失去支持的气泡柱会向上变回普通水。
- Snapshot 3：已有气泡柱向上延伸时，只检查目标是否含完整水源，能够直接把上述含水方块替换为气泡柱。拆除底座后，更新保留原来的气泡柱状态，整列仍然上推或下拉。

以含水台阶为例，延伸会移除台阶本体，调用普通方块状态替换，不会按采掘台阶生成其方块掉落物。依赖含水方块阻断气泡柱，或通过移走底座来关闭升降水道的装置，会出现不同结果。直接在灵魂沙上放一个含水方块，并不等于一定触发延伸；上述替换需要气泡柱从下方传播到它。

首次生成的延迟也改由底座上方的水方块记录。若水已等待生成气泡柱，又在这 20 刻内更换底座，新版可以沿用原先的水方块计划刻；旧版新底座重新安排自己的 20 刻检查。例如放下灵魂沙 10 刻后换成岩浆块，新版可能再过 10 刻就生成下拉气泡柱，旧版从放下岩浆块重新等待 20 刻。

## 村民不再因刚刚看见或召唤过铁傀儡而暂停召唤

新版村民没有注册“最近发现铁傀儡”的记忆。发现附近铁傀儡、成功召唤铁傀儡后写入的冷却因此失效。

### 差异出现的场景

村民已经在最近一个游戏日内睡过觉，数量和其他召唤条件满足，并处于恐慌或能够通过交流发起召唤的状态。

### 版本变化

- Snapshot 2：发现或召唤铁傀儡后，村民保留 599 刻的相关记忆；记忆存在时不参与下一次召唤。
- Snapshot 3：上述记忆写入被忽略。即使原铁傀儡仍在附近，村民也能够在下一次符合条件的检查中继续召唤。

恐慌中的检查仍然每 100 刻执行一次。因此有足够可用生成位置的刷铁装置，可以在原先约 30 秒的抑制时间内继续产生铁傀儡；生成位置被已有实体占据等其他限制仍会影响每次尝试。

## 重新加载生物会丢失部分已经保存的行为记忆

新版改为在添加行为时注册行为所需的记忆，但从存档恢复记忆发生在添加行为之前。只由行为注册、未由传感器或额外清单提前注册的记忆，会在读取存档时被忽略。

### 差异出现的场景

生物所在区块卸载后重新加载，或者保存退出后重新进入世界；存档中含有尚未失效的相应记忆。

### 版本变化

- Snapshot 2：生物的大脑预先注册这些记忆，恢复保存的值和剩余冷却。
- Snapshot 3：读取时丢弃尚未注册的记忆；之后虽然会注册相应类型，却只得到空值。

直接影响包括：

- 村民失去原来的床、工作站、潜在工作站、集合地点及最近睡眠时间等记忆。恢复后的村民需要重新建立相应关联；缺少工作站关联时不能按原关联工作补货，缺少近期睡眠记忆时不能参与召唤铁傀儡，直到重新实际睡觉。原来已经占用的床和工作站不保证还能立即被重新认领。
- 已经怀孕但尚未产卵的青蛙，重新加载后丢失怀孕状态，不能继续完成这次产卵。
- 嗅探兽的挖掘冷却不再从存档恢复，可以提前开始下一轮寻找种子；已探索地点仍在新版保留的额外记忆清单中。
- 猪灵的愤怒目标与近期狩猎记忆、山羊的冲撞和长跳冷却等，也不再沿用保存的值。

这既影响从 Snapshot 2 升级后首次读取生物，也影响在 Snapshot 3 中保存后再次读取。它与上一条铁傀儡冷却完全没有注册的问题分别发生：这里所列记忆通常可以在加载完成后的正常运行中重新写入。

## 铁傀儡、旋风人和其他生物恢复各自的攻击对象限制

新版统一了生物选择、保留攻击目标时调用的判断方法，使原先没有进入这些调用路径的种类限制实际生效。

- 玩家搭建的铁傀儡：Snapshot 2 中，玩家打伤它后，可以经反击逻辑成为目标；Snapshot 3 拒绝把玩家作为攻击目标。铁傀儡也会在目标判断中统一排除苦力怕。
- 旋风人：Snapshot 2 的附近生物搜索可以选中牛、村民等其他可攻击生物；Snapshot 3 只接受玩家和铁傀儡，因而不再被这些其他生物吸引走攻击目标。
- 使用通用生物目标判断的生物：Snapshot 2 的这些路径没有应用排除恶魂的规则；Snapshot 3 会排除恶魂，包括试图通过反击建立的恶魂目标。

## 猪灵在疣猪兽数量占优时改变受击反应

当一只成年猪灵看到的成年疣猪兽数量，多于可见成年猪灵数量加上它自己时：

- Snapshot 2：被玩家等非猪灵、非疣猪兽生物伤害，会进入逃避并向同伴传播撤退；被疣猪兽伤害反而走通常的报复分支。

## 繁殖出的村民保留按父母和繁殖地点选出的类型

### 差异出现的场景

让不同生物群系类型的村民繁殖，或者在与世界原点生物群系不同的位置繁殖村民。

### 版本变化

- Snapshot 2：先进行一次类型选择，但随后在幼村民尚未被移动到父母位置时执行出生初始化，使用幼村民默认位置 `(0, 0, 0)` 所在生物群系覆盖结果。因此此前选出的父母类型或繁殖地点类型不保留。

## 设置具名时间改为前进到下一次时刻，并增加独立世界时钟

昼夜、月相、村民日程等时间轴现在引用命名世界时钟。原版使用 `minecraft:overworld`，相关命令和自定义维度的行为随之改变。

### 差异出现的场景

在已经过了若干天的世界执行 `/time set day`、`noon`、`night`、`midnight`；或者从下界、末地及自定义维度执行时间命令。

### 版本变化

- Snapshot 2：具名设置直接把累计昼夜时间设为 1000、6000、13000、18000。任何维度中的 `/time set`、`add` 都会遍历世界应用设置。
- Snapshot 3：具名设置沿时钟向前走到该时刻的下一次出现，保留已经走过的天数；当前恰好是这个时刻时，也会前进整整一轮。数字形式 `/time set 1000` 仍直接设置累计时间。

例如累计时间为 30000 时执行 `/time set noon`，旧版变为 6000，新版变为 54000。因而具名设时不再把月相和依赖累计昼夜时间的进度一并退回第一天。依赖命令返回值的装置也有区别：新版设置、增加时间返回累计时钟值对 2147483647 取余的结果，旧版返回一天内的刻数。

新版省略时钟名称时使用执行维度的默认时钟。原版下界和末地没有默认时钟，因此在这些维度执行普通 `/time set`、`add`、`pause`、时钟查询会报错；需要用 `/time of minecraft:overworld ...` 明确指定。`/time query gametime` 仍可直接查询。

其他直接变化：

- `/time add` 可以使用负数，回退后最低为 0。
- `/time pause`、`resume` 可单独暂停和继续指定时钟。暂停只停止时钟自增，不停止实体与计划任务；睡觉和显式时间设置仍能修改该时钟。全局 `minecraft:advance_time` 仍控制所有时钟是否自增。
- 旧 `/time query daytime` 由 `/time query day` 或 `/time query minecraft:day` 取代；旧 `/time query day` 的“经过天数”含义移到 `/time query day repetition`。`/time query time` 查询累计时钟时间。旧命令即使还能解析，也可能读到不同含义的数字。
- 自定义数据包可以新增世界时钟，并让不同时间轴引用不同的时钟；维度的 `default_clock` 决定省略时钟的命令和睡觉使用哪一个。允许睡觉但没有默认时钟的自定义维度，新版睡醒时不会跳过时间。
- 时间轴和 `time_check` 条件现在必须写明 `clock`；原有自定义定义需要补上。旧存档的 `DayTime` 自动迁移到 `world_clocks` 中的主世界时钟，迁移保留原来的累计数值。

新版把许多写死的支持方块改为 `supports_*`、`cannot_support_*` 等标签。数据包能够分别控制作物、瓜茎、可可果、仙人掌、紫颂植物、下界植物、红树胎生苗等的支持方块，也能修改气泡柱的推动底座、可占据流体，及荷叶、青蛙卵和甘蔗对相邻流体的要求。修改青蛙卵支持标签同时影响青蛙选择产卵位置。

## 动画、旁观操作与调试显示调整

- 旁观者左键附身使用独立操作，不再先受手中物品的可攻击性、蓄力或自定义攻击距离限制；例如切到旁观模式前手中保留长矛时，新版仍可按正常实体交互距离附身。
- 副手挥动时，动画时长与挥动类型改为读取实际挥动的副手物品，戳刺姿势也应用到对应手臂。旧版这些判断部分固定取主手，两个手持有不同挥动配置时会显示错误动画。
- 正常没有拴绳数据的兔子，旧版不会开始闲置歪头动画；新版可以播放。拴绳数据改变时会停止正在播放的歪头。
- 调试界面的天数从本地区域难度一行拆出为独立的 `day_count` 项目，读取 `minecraft:day` 时间轴的累计周期数；原版各维度都可读取同一个主世界时钟的天数。
- 绊线从带透明混合的专用绘制层改为裁切绘制层；资源包中半透明但未被裁切丢弃的像素，现在按不透明像素显示。
- 物品对话框在布局更新后重新排列正文滚动区域，减少正文位置未随布局更新的问题。
