# Minecraft 26.1-snapshot-4 变更分析

- 上一个版本：`26.1-snapshot-3`
- 当前版本：`26.1-snapshot-4`

## 西瓜和南瓜恢复在泥土类方块上结果

西瓜茎和南瓜茎结果时会检查相邻空位下方的方块。新版扩大了结果基底，并把两种瓜的结果基底分别交给标签控制。

### 差异出现的场景

成熟瓜茎尝试向相邻空气位置生成西瓜或南瓜，目标下方为原版 `dirt` 标签中的方块，且满足其余生长条件。

### 版本变化

- Snapshot 3：结果位置下方必须是耕地；上述泥土类方块不能作为结果基底。
- Snapshot 4：耕地和 `dirt` 标签中的方块均可作为结果基底。新增可用的基底包括泥土、草方块、灰化土、砂土、菌丝体、缠根泥土、苔藓块、苍白苔藓块、泥巴和沾泥的红树根，铺设这些方块的结果位置重新能够产出瓜。

新版分别使用 `supports_melon_stem_fruit` 和 `supports_pumpkin_stem_fruit` 标签，默认均引用 `supports_stem_fruit`。数据包可以分别调整两种瓜的结果基底，而无需同时改变瓜茎本身的种植基底。

## 甘蔗可以种在红沙和可疑的沙子上

甘蔗可用的沙类基底由普通沙子扩大为整个 `sand` 标签。

### 差异出现的场景

玩家在红沙或可疑的沙子上种植甘蔗，或已有甘蔗在这些基底上接受存活检查；相邻水等其他条件均已满足。

### 版本变化

- Snapshot 3：沙类基底只接受普通沙子，红沙和可疑的沙子不能支撑甘蔗。
- Snapshot 4：改为接受 `sand` 标签，原版数据中的红沙和可疑的沙子也能支撑甘蔗。

## 气泡柱随底座移除而消退，天然水下岩浆会触发生成

气泡柱会根据下方方块决定是否存在以及推动方向。新版修复了失去底座后仍保留气泡柱的情况，并补充了水源受到邻居更新时的生成检查。

### 差异出现的场景

移走或替换已有气泡柱下方的灵魂沙、岩浆块；或者符合气泡柱生成条件的水源收到邻居更新，包括世界生成在水下放置岩浆块的情况。

### 版本变化

- Snapshot 3：气泡柱检查到下方既非气泡柱、也不能产生气泡柱时，仍保留原状态；移除底座后可能留下无源气泡柱。水源收到普通邻居更新时不会额外安排气泡柱检查，天然水下岩浆放置后也不会主动更新上方水，需要后续更新才能触发生成。
- Snapshot 4：失去支撑的气泡柱恢复为水源，并沿连续水柱向上传递；相关形状更新通常会安排 5 游戏刻后的检查。水源收到邻居更新后，若下方能产生气泡柱，会安排 20 游戏刻后的生成检查；天然水下岩浆放置时也会主动更新正上方方块，触发这条路径。

借助移除底座保留的无源气泡柱，在收到相应更新后会失效。

## 疣猪兽与僵尸疣猪兽恢复近战攻击

疣猪兽和僵尸疣猪兽的成年、幼年近战行为都通过条件包装来选择。新版修复包装行为漏登记攻击冷却记忆的问题，使近战行为能够启动。

### 差异出现的场景

疣猪兽或僵尸疣猪兽已有可攻击目标，目标可见且进入近战范围。

### 版本变化

- Snapshot 3：会追踪目标，但近战行为无法通过启动条件，不能正常打出攻击。
- Snapshot 4：能够正常攻击，成年个体的攻击间隔为 40 游戏刻，幼年个体为 15 游戏刻。

依赖旧版疣猪兽贴近目标后仍不造成伤害的配置会受影响；用僵尸疣猪兽击杀其他生物的装置也恢复自动攻击能力。

## 村民重新受到铁傀儡检测与生成冷却限制

村民检测到附近铁傀儡，或附近村民成功生成铁傀儡后，会记录一段暂时禁止再次生成铁傀儡的时间。本次修复使这段记录真正生效。

### 差异出现的场景

村民已满足最近睡眠、恐慌或交谈等生成铁傀儡所需条件，同时附近已有被检测到的铁傀儡，或刚刚成功生成了铁傀儡。

### 版本变化

- Snapshot 3：检测器没有登记用于记录“最近检测到铁傀儡”的记忆，写入记录时被忽略；已有或刚生成的铁傀儡不能通过这项记录阻止村民再次尝试生成。
- Snapshot 4：这项记忆得到登记。每次检测到铁傀儡，或附近成功生成铁傀儡，都会写入持续 599 游戏刻、约 30 秒的禁止生成记录。村民在记录有效期间不参与再次生成。

### 实际影响

铁傀儡农场恢复了这项频率限制。即使刚生成的铁傀儡立即被移出检测范围，相关村民仍需等待此次记录到期；若铁傀儡持续被检测到，记录会被刷新。检测器本身每 200 游戏刻检查一次附近生物。

## 生物重新加载后保留更多已有记忆与冷却

生物存档中的部分 AI 记忆依赖行为登记后才能读回。新版把行为登记移到读取记忆之前，使这些位置、状态和剩余冷却能够保留。

### 差异出现的场景

生物已具有下表所列的记忆，随后因区块卸载、退出世界或服务器重启而保存并重新加载；对应记忆仍存在于读取的存档中。

### 版本变化

- Snapshot 3：下表中的位置、状态和剩余冷却虽然可以写进存档，但重新加载时会丢失。
- Snapshot 4：在对应记忆仍存在于存档中的前提下，读取时保留这些值，带有效期的记忆保留剩余计时。

| 涉及生物与场景 | 新版重新加载后的表现 |
| --- | --- |
| 村民已认领床、工作站或钟 | 保留床、工作站、待认领工作站和集合点的位置；最近睡眠、醒来的时间也能保留。铁傀儡农场中的村民不再仅因重新加载就失去此前满足的最近睡眠条件。 |
| 青蛙已经交配、尚未产卵 | 保留待产状态，之后找到合适位置仍能产下青蛙卵；长跳的剩余冷却也能保留。 |
| 蝾螈正处于装死计时内 | 保留剩余装死计时，重新加载不再立即清空这段状态。 |
| 山羊正处于冲撞或长跳冷却 | 继续等待原有剩余冷却，重新加载不再清除这两段等待时间。 |
| 嗅探兽已经挖掘过种子 | 保留本次挖掘后剩余的嗅探冷却；原本总长 9600 游戏刻、8 分钟的等待不能再通过重新加载清空。 |
| 铜傀儡已经检查过箱子，或发现无法到达的箱子 | 保留尚未过期的已访问位置和无法到达位置记录，重新加载后不会仅因记录丢失而重新从这些位置开始尝试。 |
| 猪灵、猪灵蛮兵已经被激怒 | 保留愤怒对象及其剩余有效时间；猪灵的欣赏物品、暂停欣赏、最近狩猎记录，以及猪灵蛮兵的原活动位置也能保留。 |
| 监守者仍处于等待钻地消失的时间内 | 保留剩余等待时间，不再仅因重新加载丢掉这段计时而提早进入钻地流程；嗅探、音波攻击等已登记的计时与状态同样可读回。 |
| 鹦鹉螺、僵尸鹦鹉螺刚完成冲刺攻击 | 保留冲刺攻击的剩余冷却。 |
| 悦灵刚交付物品，或使用这套 AI 的动物刚停止受食物引诱、仍在惊慌 | 相应的拾取冷却、引诱冷却、惊慌状态可以读回，而不是因加载被统一清空。 |

旋风人的跳跃目标、跳跃和射击阶段记忆也纳入相同的读取顺序修复。这里保留的是存档中已有的记忆；并非所有运行中的行为对象、攻击目标或寻路过程都会完整保存。

## 猪灵可以在同伴附近正常发起狩猎

猪灵主动狩猎疣猪兽时，会检查可见成年同伴的狩猎冷却。新版修复了这项检查，使没有处于冷却的同伴不会阻止狩猎。

### 差异出现的场景

成年猪灵自身没有狩猎冷却、没有愤怒对象，并看见可狩猎的疣猪兽；附近有可见的成年猪灵，且这些同伴均未处于狩猎冷却。

### 版本变化

- Snapshot 3：仅因检测到这些同伴就会阻止主动狩猎，没有按同伴实际冷却状态作出区分。
- Snapshot 4：只有可见成年同伴中确实存在尚在狩猎冷却的个体时才阻止狩猎；上述条件下可以正常发起狩猎。

发起狩猎后仍会通知附近可见的成年猪灵，写入狩猎冷却并传播攻击目标。将多只猪灵放在一起不再使它们一直无法主动狩猎疣猪兽。

## 幼年马、骷髅马和僵尸马的碰撞箱变大

幼年马、幼年骷髅马和幼年僵尸马的尺寸缩放由成年尺寸的 0.5 倍改为 0.7 倍，改变了它们能通过的空间。

### 差异出现的场景

上述三种幼年个体经过狭窄通道，尤其是利用成年与幼年高度差进行分流、隔离的结构。

### 版本变化

## 零数量需求的自定义交易不再生成

交易生成器现在会检查最终需求数量，排除主需求或已配置的第二需求少于 1 个物品的候选交易。

### 差异出现的场景

自定义交易计算完附魔等额外价格后，主需求或已配置的第二需求数量为 0。

### 版本变化

- Snapshot 3：仍生成这笔交易；这样的零数量报价还会违反交易存档要求成本数量为正数的约束。
- Snapshot 4：跳过该候选交易，并继续尝试交易池中的其他候选。

检查发生在额外价格计入之后。因此，图书管理员定义的基础绿宝石数量为 0，但加上有效附魔价格后达到正数，仍能正常生成交易。只需一种物品的交易可以省略第二需求；配置数量为 0 的第二需求会使该候选被排除。

## 沉船跨区块生成时沿用首次确定的高度

沉船模板可能分多次放入不同区块。新版记录首次确定的高度，避免后续区块重复计算而使船体出现高度断层。

### 差异出现的场景

同一艘沉船分多次放置，尤其是带有随机下沉量的搁浅沉船；也包括保存、加载后继续生成剩余部分。

### 版本变化

- Snapshot 3：每次放置都重新计算高度，搁浅沉船还会再次使用随机下沉量，不同区块中的船体部分可能落在不同高度。
- Snapshot 4：首次计算后记录“已经调整高度”，后续放置沿用该高度；标记也写入结构存档，保存、加载后仍可沿用。

修复影响之后放置的沉船部分，不会回填已经生成的断层方块。旧存档中缺少标记的结构，下次执行时仍会先计算一次高度。

## 末地闪光改用独立时钟，可暂停或改变相位

末地天空闪光由时间驱动。新版为末地增加独立的 `minecraft:the_end` 时钟，使时间命令和时间推进规则可以控制闪光。

### 差异出现的场景

在末地执行使用当前维度默认时钟的 `/time pause`、`/time resume`、`/time set <数值>` 或 `/time add <数值>`，或者关闭 `minecraft:advance_time` 规则。

### 版本变化

- Snapshot 3：末地没有默认时钟，上述需要默认时钟的命令会失败。天空闪光按持续递增的游戏总时间推进，关闭时间推进规则后仍会变化。
- Snapshot 4：命令使用末地时钟；暂停、恢复可以停住或继续闪光变化，设置或增加时间可以改变闪光所处的时间位置。关闭 `minecraft:advance_time` 也会停住闪光的时间。

## 实体、方块实体与粒子的透明内容在不透明部分之后绘制

实体、方块实体和粒子同时包含不透明与半透明内容。新版按透明度划分绘制阶段，改变这些内容重叠时的遮挡与混合顺序。

### 差异出现的场景

实体、方块实体或粒子的半透明部分，与其他对象的不透明部分在画面中相互重叠。

### 版本变化

- Snapshot 3：按实体、方块实体等类别依次提交完整内容，粒子在后续步骤绘制，半透明部分可能早于其他物体的不透明部分绘制。
- Snapshot 4：先完成实体、方块实体与粒子的不透明部分，再绘制半透明部分；使用单独透明度缓冲区时，也在不透明部分完成后复制深度。这修正了旧顺序引起的部分透明内容显示异常。

代码出处：[Snapshot 3：旧版完整绘制后再绘制粒子](https://github.com/TISUnion/guardian/blob/20a4ab503f5b0d4fe78d8e6563c361bb5981c242/src/main/java/net/minecraft/client/renderer/LevelRenderer.java#L676)；[Snapshot 4：新版先绘制不透明部分及复制深度](https://github.com/TISUnion/guardian/blob/cba3802fe1e0430fe14c5f9ed102faed0a9afbc6/src/main/java/net/minecraft/client/renderer/LevelRenderer.java#L679)；[Snapshot 4：新版半透明绘制阶段](https://github.com/TISUnion/guardian/blob/cba3802fe1e0430fe14c5f9ed102faed0a9afbc6/src/main/java/net/minecraft/client/renderer/feature/FeatureRenderDispatcher.java#L65)。

## 幼年马的模型、装备显示与声音调整

新版重做了幼年马的身体模型，调整幼年个体的装备层显示，并为普通幼马选择独立的声音事件。

### 差异出现的场景

观察幼年马、骷髅马、僵尸马、驴或骡；通过命令给这些幼年个体设置鞍，或给幼年马、骷髅马、僵尸马设置马铠；以及普通幼马发出叫声、脚步和落地声音时。

### 版本变化

- Snapshot 3：幼年马、骷髅马和僵尸马使用由成年模型调整而来的幼年模型，幼年驴、骡沿用旧版幼年模型；上述幼年个体会绘制相应的鞍或马铠。普通幼马沿用成年声音事件。
- Snapshot 4：幼年马、骷髅马和僵尸马使用重新制作的幼年身体模型，幼年驴、骡使用专门的幼年模型；这些幼年个体不再绘制相应的鞍或马铠装备层。普通幼马的环境叫声、受伤、死亡、进食、生气、喘息、普通脚步和落地改用独立的幼年声音事件。
