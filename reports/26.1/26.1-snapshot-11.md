# Minecraft 26.1-snapshot-11 变更分析

- 上一个版本：`26.1-snapshot-10`
- 当前版本：`26.1-snapshot-11`

## 龙蛋传送不再选择下方也是空气的位置

玩家点击龙蛋触发传送时，新版缩小了可接受落点的范围。

### 差异出现的场景

随机选中的目标方块是空气、位于世界边界和建造高度内，但目标正下方同样是空气，例如高空平台周围或洞穴中的悬空位置。

### 版本变化

- Snapshot 10：上述位置可以成为落点，龙蛋随后按重力下落。
- Snapshot 11：拒绝上述位置，继续寻找下一个落点。必须找到正下方为非空气方块的位置才能传送；1000 次尝试都失败时，龙蛋留在原处。

新条件只要求下方不是空气，水、火把等非空气方块也能满足这一项检查。因此，传送后的龙蛋仍可能下落，依赖龙蛋落到火把等方块上掉落物品的操作仍可能发生，但依靠传送进入连续空气区域的落点设计会改变。

## 命名牌从图书管理员交易中移出，流浪商人开始出售

这次修改改变了后续生成的交易与箱子战利品，不会把已保存的商人交易或已经生成的箱内物品直接替换掉。

### 差异出现的场景

图书管理员新解锁大师级交易、流浪商人首次生成交易，或远古城市、林地府邸的箱子首次结算战利品。

### 版本变化

- Snapshot 10：图书管理员的大师级交易包含基础价 20 颗绿宝石购买 1 个命名牌；流浪商人没有命名牌交易；远古城市和林地府邸的对应箱子战利品表包含命名牌。
- Snapshot 11：图书管理员的大师级候选交易改为黄色蜡烛和红色蜡烛，分别以基础价 3 颗绿宝石购买 1 根，每项最多使用 12 次。普通交易设置下，这一级只有这两项候选，因而会解锁两种颜色。流浪商人的普通商品池加入基础价 1 颗绿宝石购买 1 个命名牌的交易，每次出现最多购买 5 个；这项交易是随机抽选商品之一，并非每位商人都有。两个结构的上述箱子战利品表均移除命名牌。

启用村民交易平衡实验时，图书管理员的大师级候选池同样用这两种蜡烛替换命名牌；该实验的远古城市战利品表也同步移除命名牌。已保存的命名牌交易继续按原报价和补货机制运行。旧世界中尚未结算战利品的相关箱子会使用新版表，因此也不再从这些表产出命名牌。

## 流浪商人及随行羊驼改用忽略树叶的生成高度

流浪商人事件会先为商人及两只随行羊驼寻找生成位置。新版改变了这一步使用的高度图，使树冠和部分地表植物不再决定尝试高度。

### 差异出现的场景

事件在一列覆有树冠或不阻挡运动的无流体植物的地面上选择生成位置；商人与羊驼仍需通过地面放置、空间和生物群系等检查。

### 版本变化

- Snapshot 10：使用 `WORLD_SURFACE` 高度图，在最上方非空气方块之上的位置尝试生成。例如有树冠时，先在树冠上方尝试。
- Snapshot 11：使用 `MOTION_BLOCKING_NO_LEAVES` 高度图，忽略树叶和不阻挡运动的无流体方块，转而在下方符合高度图条件的表面上尝试。满足其余检查时，商人与羊驼可以生成在树下。

树叶仍占据实体所需空间的位置会继续失败。依靠树冠或地表植物让事件选中不合适高度的生成控制方式会受到影响。

## 锁定年龄的行商羊驼不再因专用倒计时消失

行商羊驼有独立的消失倒计时。新版把年龄锁定加入倒计时的暂停条件，使金蒲公英保留的幼体不再被这条逻辑清除。

### 差异出现的场景

幼年行商羊驼已经锁定年龄，同时未驯服、没有玩家乘坐，也未被拴到商人以外的对象上。

### 版本变化

- Snapshot 10：年龄锁定不阻止专用倒计时；满足原有消失条件时，倒计时继续推进，到期后羊驼被移除。
- Snapshot 11：年龄锁定期间跳过专用倒计时及移除处理。解除锁定后，若仍满足其他消失条件，恢复倒计时处理。

## 内置洞穴和浮岛噪声设置失去主体地形

内置 `minecraft:caves` 和 `minecraft:floating_islands` 噪声设置出现了会改变新生成区域的回归。它们供自定义生成器或数据包引用，不是普通主世界和末地默认使用的噪声设置。

### 差异出现的场景

噪声生成器通过上述两个内置键引用设置，并继续生成尚未生成的区块。

### 版本变化

- Snapshot 10：`final_density` 保存实际地形密度函数，决定洞穴的岩体或浮岛的位置。
- Snapshot 11：`final_density` 变成常数 0，原地形密度函数被放到了 `vein_gap`。两个设置均关闭大型矿脉，因此原函数不再用于生成主体岩石。

对于没有结构地形适配影响的位置，密度 0 会直接进入全局流体选择：`caves` 在其生成范围内主要形成低处熔岩、其上至 Y=31 的水和 Y≥32 的空气；`floating_islands` 的海平面为 -64，低于它从 Y=0 开始的生成范围，因此主体成为空气。这里描述的是噪声填充阶段的结果；结构、地物等后续生成仍可能放置方块。

这会使使用这些设置的旧世界在新旧区块边缘出现明显断层，已经生成的岩体和浮岛不会因加载而自动重写。另外，两项设置中的温度、湿度采样同时改为常数 0；若自定义生成器以这些采样值选择生物群系，选择结果也会改变。

## 下界气候噪声改为独立可配置参数

下界使用温度、湿度噪声选择生物群系。新版为旧式下界噪声增加独立键，并允许从数据文件读取参数；默认下界保留原来的种子偏移、八度和振幅，生物群系不会仅因这次调整重新排列。

### 差异出现的场景

自定义噪声设置启用 `legacy_random_source`，并引用 `minecraft:temperature`、`minecraft:vegetation` 或 `minecraft:offset`；或者数据包需要调整原版下界的气候噪声参数。

### 版本变化

- Snapshot 10：启用 `legacy_random_source` 时，两个通用气候键会被强制替换为固定参数的旧式下界噪声，`minecraft:offset` 被强制置零。覆盖通用气候噪声文件不能改变这组固定参数。
- Snapshot 11：旧式下界初始化改为绑定 `minecraft:nether/temperature` 和 `minecraft:nether/vegetation`，读取各自数据文件的参数，不再由 `legacy_random_source` 决定。原来的三个通用键恢复正常采样，覆盖两个新键的数据文件可以调整原版下界的气候噪声。

沿用旧通用键的自定义下界生成器可能改变生物群系分布及依赖这些采样的生成结果。原版下界已改用新键和显式的零坐标偏移；旧版的这一偏移本就被置零。

## 树叶防凋落支持方块可单独配置

树叶通过与支撑方块的距离决定是否凋落。新版为距离起点增加独立标签，数据包可以单独调整支撑来源。

### 差异出现的场景

数据包需要让原木以外的方块支撑附近树叶，或移除某些原木的支撑作用；相关树叶发生更新并重新计算距离。

### 版本变化

- Snapshot 10：直接把 `#minecraft:logs` 内的方块作为距离 0 的起点；改变这类支撑需要修改原木标签，并同时影响该标签的其他用途。
- Snapshot 11：改读 `#minecraft:prevents_nearby_leaf_decay`。数据包可以添加方块，或用 `replace` 重定义支撑集合，影响相邻树叶及经树叶传递的距离。

新版默认标签包含整个 `#minecraft:logs`，因此默认数据下树叶的凋落范围保持原样。

## 规则方块提供器扩展到更多生成及附魔效果

规则方块提供器根据周围方块、流体等条件选择放置的方块。新版把它注册为通用类型 `minecraft:rule_based_state_provider`，同时改变了原来几个专用入口的数据格式。

### 差异出现的场景

数据包在树干、树叶、紫晶洞、植被、方块柱或附魔的 `replace_block`、`replace_disk` 等入口使用方块提供器；或者继续加载圆盘、树下方块和树木地面装饰的旧规则配置。

### 版本变化

- Snapshot 10：规则提供器专供圆盘的 `state_provider`、树木的 `below_trunk_provider` 和 `alter_ground` 的 `provider` 使用，这些位置直接读取不带类型的规则对象。其余通用入口不能选择这一规则类型。
- Snapshot 11：这些位置统一使用通用方块提供器格式，原规则对象需要增加 `"type": "minecraft:rule_based_state_provider"`；只提供固定后备状态的对象也可改写为普通状态提供器。通用入口由此可以使用条件规则。圆盘和地面装饰的旧对象不再能正常解析；树木字段解析失败时退回默认树下方块规则，可能使自定义树下方块改为泥土。

规则依次采用第一个满足条件的分支，再尝试 `fallback`。两者都没有结果时，圆盘、树下方块、地面装饰和简单方块地物跳过该次放置；其他需要明确方块状态的入口返回原位置的方块状态。原版生成数据已同步改写，等价规则本身没有改变树木或圆盘的正常生成结果。
