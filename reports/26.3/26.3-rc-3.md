# Minecraft 26.3-rc-3 变更分析

- 上一个版本：`26.3-rc-2`
- 当前版本：`26.3-rc-3`

## 攻击其他玩家时，本机继续执行命中后的处理

新版调整了客户端对其他玩家的命中判断，影响冲刺攻击后的自身减速，以及近战和箭的本地反馈。

### 差异出现的场景

玩家在多人游戏中对另一名玩家发动普通近战攻击。本机已经选中该玩家，攻击能够进入伤害计算；其中最明显的操作差异出现在攻击充能超过 90% 的冲刺攻击。

### 版本变化

- 26.3-rc-2：本机把其他玩家的这次受击判为失败，跳过命中后的自身减速和结束冲刺处理。即使服务器随后确认命中，本机在发动攻击时也没有执行这一步。
- 26.3-rc-3：本机把其他玩家的受击判为成功，继续执行命中后的处理。上述冲刺攻击会立即把攻击者已有的水平速度乘以 0.6，并结束冲刺。因此，连续冲刺攻击时，本机的移动和重新进入冲刺的时机会发生变化。

同一修改还带来以下反馈差异：

- 对其他玩家打出重击时，旧版的暴击粒子依赖服务器发来的攻击动画消息；新版本机在攻击时就会额外生成一轮暴击粒子。
- 箭在客户端与其他玩家相撞时，旧版进入受击失败分支，反向弹回；新版进入命中分支，没有穿透能力的箭立即在本机消失，有穿透能力的箭按穿透流程继续处理。这里比较的是客户端自行碰撞判定到服务器结果同步之间的表现。

上述改动涉及本机提前执行的攻击结果。实际扣血、无敌及服务器的玩家间伤害限制仍由服务器判定；本地出现命中反馈并不表示服务器已经接受这次伤害。

## 编辑服务器时，服务器资源包选项能够保存

在多人游戏列表中，选中已经保存的服务器，进入编辑界面，更改“服务器资源包”的“启用”“禁用”或“询问”选项并点击“完成”：

- 26.3-rc-2：只把编辑后的名称和地址写回服务器列表，资源包选项仍保留修改前的值；下次连接继续使用旧选择。
- 26.3-rc-3：同时保存资源包选项，下次连接使用新选择。例如，原来为“询问”的服务器改成“启用”后，新版会自动接受其资源包，旧版仍会询问；改成“禁用”后，新版会自动拒绝可选资源包，强制资源包仍会要求确认。

## OpenGL 启动时把垂直同步设置应用到游戏窗口

使用 OpenGL 渲染器启动游戏时，旧版首次配置窗口的垂直同步设置前，OpenGL 仍指向初始化用的隐藏窗口；直到呈现画面时才切到游戏窗口。在交换间隔按窗口分别生效的环境中，这会使启动时的垂直同步设置没有应用到实际游戏窗口。

26.3-rc-3 会先切换到游戏窗口，再根据“垂直同步”选项设置交换间隔，修正这类启动后选项与实际呈现行为不一致的情况。具体表现取决于窗口系统和显卡驱动；这一改动适用于 OpenGL 渲染器。
