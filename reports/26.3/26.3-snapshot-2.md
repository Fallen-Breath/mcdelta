# Minecraft 26.3-snapshot-2 变更分析

- 上一个版本：`26.3-snapshot-1`
- 当前版本：`26.3-snapshot-2`

## 流体可以冲掉蜘蛛网、竹笋和杨树树苗

流体通过可冲走方块标签判断能否替换目标位置。新版把蜘蛛网和竹笋加入该集合，杨树树苗则通过加入树苗标签获得相同行为。

### 差异出现的场景

水或熔岩流向蜘蛛网、刚种下尚未长成竹子的竹笋或杨树树苗，且满足原有的流动和进入目标位置的条件。

### 版本变化

- Snapshot 1：这三类方块会阻挡流体，不被流体替换。
- Snapshot 2：流体替换这些方块。水流执行正常无工具掉落：蜘蛛网掉落线，竹笋掉落竹子，杨树树苗掉落自身；熔岩替换时不执行这次掉落。

### 实际影响

利用蜘蛛网维持水路边界或减速实体的装置，在水流进入蜘蛛网所在位置后会失去蜘蛛网。新种竹子的初始阶段也可以直接用水流破坏。

## 溺尸在三格距离处切换攻击方式

溺尸新增按目标距离切换近战和投掷三叉戟的限制。这一限制也作用于没有三叉戟的溺尸。

### 差异出现的场景

溺尸已经选定可攻击的目标，并满足原有的昼夜、目标所处环境等攻击条件。这里的三格指两个实体位置之间的三维距离。

### 版本变化

- Snapshot 1：持三叉戟的溺尸可以对近距离目标继续投掷；没有三叉戟的溺尸可以通过近战目标追赶三格以外的目标。
- Snapshot 2：目标距离至少三格时，只允许启动或继续远程攻击；目标距离小于三格时，只允许近战。持三叉戟者会改为近战攻击靠近的目标。没有三叉戟者在目标至少三格远时，近战被禁止，又不满足远程攻击持有三叉戟的条件，因此不能通过这两个攻击目标追赶或攻击该目标。

最后一种情况不代表溺尸完全停止移动；寻水、上岸和其他移动目标仍可运行。依赖无三叉戟溺尸持续追赶玩家的引流方式，以及让持三叉戟溺尸贴近玩家持续投掷的装置，都会受到影响。

## 持久化生物在玩家远处也会累计空闲时间

命名等方式获得持久性的生物，以及被特殊机制保留的生物，新版不再每次检查消失条件时无条件清零空闲计时。这不会取消它们的持久性，但会影响共用该计时的行动和袭击机制。

### 差异出现的场景

生物所在区块继续进行实体运算，最近玩家处于该生物种类的“不随机消失距离”之外，或者该维度没有玩家。常见生物的该距离为32格。生物没有因受伤或自身其他逻辑而重置空闲计时。

### 版本变化

- Snapshot 1：有持久性或特殊保留条件的生物持续清零计时，因此不会因这个计时而停止随机游荡。
- Snapshot 2：持久性只阻止距离消失，不再阻止计时累计。玩家进入上述距离内才由通用逻辑清零计时。

### 实际影响

使用通用随机游荡目标、且启用了空闲检查的生物，计时达到100后不再主动开始该随机游荡目标；例如命名生物在远离玩家但仍运算的区域里不再一直随机走动。命名鱿鱼的随机游动目标在计时超过100后将游动向量清零。

活动袭击本身也会赋予袭击成员特殊保留条件。新版允许长期滞留村庄外、没有被战斗逻辑重置计时的成员累计超过2400的空闲时间，进而触发原有的退出袭击计数；旧版的持久性清零会阻止这条计时路径。利用远处滞留成员拖住袭击进度时，其持续时间因而可能变化。

## 铲熄灭营火改由营火交互处理

铲熄灭营火从物品使用逻辑移到营火自身的交互逻辑，改变了耐久消耗、点击面限制和若干使用条件。普通营火和灵魂营火均适用。

### 差异出现的场景

玩家持铲点击燃烧的营火。除一般使用外，还包括从底面点击、潜行使用、冒险模式使用，以及自定义铲处于冷却期间的情况。

### 版本变化

- Snapshot 1：从底面点击不能熄灭；其他面成功熄灭时损耗一点耐久，并先后发出两次方块改变游戏事件。潜行仍可熄灭。冒险模式需要铲的 `can_place_on` 许可，物品冷却也会阻止操作；成功使用计入铲的使用次数。
- Snapshot 2：未按住潜行键进行次要使用时，任意面都能熄灭，不损耗耐久，只发出一次方块改变游戏事件。潜行会跳过营火交互，而铲不再自行处理熄灭，因此不能熄灭营火。冒险模式无需上述物品许可；自定义铲即使处于冷却期间也能熄灭。该交互不再增加铲的使用次数。

新版用物品标签 `minecraft:dowses_campfires` 决定可用于熄灭营火的物品，默认包含所有铲，数据包可以更改这一集合。正常使用先由营火处理，因此副手持盾也不会触发下述方块变换的格挡优先限制。

## 副手持盾时，锄和铲优先让玩家格挡

斧、锄、铲统一通过 `minecraft:block_transformer` 物品组件变换方块。锄和铲因此采用斧已有的副手格挡优先规则，并改变自定义进度检查的时机。

### 差异出现的场景

主手拿锄或铲，副手拿盾等带有 `blocks_attacks` 组件的物品，且没有按住潜行键进行次要使用；目标方块原本允许耕地、砂土变泥土、缠根泥土取出垂根或铲出土径。

### 版本变化

- Snapshot 1：主手锄或铲直接执行相应的方块变换。成功使用时，`item_used_on_block` 进度条件只在变换后检查现场。
- Snapshot 2：跳过这些方块变换，让使用动作继续处理副手物品；按住潜行键可继续执行变换。成功的锄、铲变换还会在变换前检查一次进度条件，外层原有的变换后检查仍保留，因此按原方块类型筛选的自定义进度可能额外触发。

新版还用 `turns_into_farmland`、`turns_into_dirt_path` 方块标签控制常规耕地与土径的来源，用 `minecraft:till/rooted_dirt` 战利品表决定从缠根泥土取出的掉落物。旧版这些对应关系由锄、铲自身的固定逻辑决定。

## 投射物破坏方块新增发射者与冒险模式权限检查

饰纹陶罐、紫颂花，以及只能被达到速度要求的三叉戟打碎的滴水石锥和硫黄尖锥，改为共用新的投射物破坏权限。

### 差异出现的场景

冲击型投射物击中上述方块；原有的 `projectiles_can_break_blocks` 规则、交互权限、速度及投射物类型等条件均满足。

### 版本变化

- Snapshot 1：冒险模式玩家也可以用普通投射物打碎饰纹陶罐和紫颂花；滴水石锥等尖锥则单独检查三叉戟物品的 `can_break`。非玩家发射或没有发射者的投射物，只要满足其他条件，也可以破坏相应方块。
- Snapshot 2：仅当发射者是非冒险模式玩家时直接通过新增检查。冒险模式玩家、非玩家发射者及无发射者投射物，都必须让投射物自身保存的 `can_break` 条件匹配被击中的方块。默认物品没有该条件，因此骷髅、溺尸和发射器等来源的普通投射物不能再按原规则打碎这些方块。

### 实际影响

使用发射器或生物远程攻击自动打碎陶罐、紫颂花，或让溺尸投掷三叉戟打碎尖锥的装置，默认条件下会停止破坏方块。

权限的传递还有两个限制：弓箭和三叉戟在创建时会从所携带的物品复制 `can_break`，应把组件放在箭或三叉戟上；普通雪球、鸡蛋的物品构造路径只设置显示物品，不复制这一组件，因此仅给这些物品添加 `can_break` 不能使冒险模式下的投掷通过检查。箭和三叉戟重新从存档加载时也只恢复物品，没有重新复制这个新字段；冒险模式下，原本获准破坏方块的投射物若经历卸载、重载，会失去这份运行时权限。

## 海豚可以在其他移动行为期间抛出物品

海豚寻找掉落物与抛出手中物品原本共用一个目标。新版拆开两个动作，让抛出物品不再独占移动控制，并提高寻找物品的优先级。

### 差异出现的场景

海豚手中已有物品，同时正在游向玩家等更高优先级的移动行为；或附近有可拾取的掉落物，同时可以跟随玩家乘坐的船或鹦鹉螺。

### 版本变化

- Snapshot 1：抛出物品需要运行共用的移动目标，可能因其他移动行为而一直拿着物品。寻找物品和跟随坐骑的目标均为优先级8。
- Snapshot 2：独立的抛出目标不占用移动控制，其他移动行为进行期间也能抛出物品。寻找物品提高到优先级7，优先于原优先级8的跟随坐骑目标，因而更容易先游向物品。

物品抛出后的40刻拾取延迟和抛掷速度保持原值。

## 密度函数范围修正会改变部分自定义地形

密度函数的取值范围用于 `min`、`max` 等运算的提前返回。新版修正部分范围推导，避免错误范围改变实际求值，同时拒绝上下限倒置的 `clamp` 定义。

### 差异出现的场景

自定义地形使用受错误范围推导影响的函数，并在外层组合 `min`、`max`；例如输入始终在0.1到0.2之间的平方函数，外层为 `min(0.05, 平方结果)`。另一个适用场景是 `clamp` 定义中 `min > max`。

### 版本变化

- Snapshot 1：该平方函数的范围下限被误算为0.1，可能使外层运算提前返回0.05，而非实际平方结果；`clamp` 也未拒绝上述上下限倒置的定义。
- Snapshot 2：平方范围正确推导为0.01到0.04，外层运算按正确范围求值。依赖原错误结果的自定义地形会变化；上下限倒置的 `clamp` 定义在加载时被拒绝。
