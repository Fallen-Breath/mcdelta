# Minecraft 26.3 Snapshot 4 变更分析

- 上一个版本：`26.3-snapshot-3`
- 当前版本：`26.3-snapshot-4`

## 普通告示牌不再充当地面判定中的阻挡方块

竖立和墙上的普通告示牌从通用阻挡方块标签中移除，改变使用该标签的传送、破冰和高度图判定。悬挂式告示牌保留原有归类。

### 差异出现的场景

普通告示牌位于随机传送的落点下方、冰的正下方，或成为某一列最高的阻挡方块；破冰场景要求没有精准采集，且所在维度允许留下水。

### 版本变化

- Snapshot 3：普通告示牌计入上述阻挡判定。随机传送向下寻找地面时会在它处停止；破坏其上方的冰可以留下水，相关高度图也将它计作阻挡高度。
- Snapshot 4：随机传送会越过普通告示牌继续向下找地面，可能选中更低的落点或找不到落点。冰下方只有不含水的普通告示牌时，不再因它而留下水；相关高度图也不再计入它。熔岩随机向上点火的搜索经过普通告示牌时，不再因这一阻挡标签而提前停止。

普通告示牌同时被明确加入阻挡流体的标签，原有挡水、挡熔岩用途继续适用。

## 僵尸离水会取消已经开始的转化

僵尸转为溺尸、尸壳转为僵尸都要先累计浸水时间，再进入发抖的转化倒计时。新版在倒计时期间继续检查眼睛是否浸水。

### 差异出现的场景

僵尸或尸壳已经开始发抖，但在转化完成前被水流、活塞或升降机构移出水面。

### 版本变化

- Snapshot 3：开始转化后的倒计时独立于是否还在水中，离水后仍会完成转化。
- Snapshot 4：眼睛离开水后立即取消转化，并清除此前累计的浸水时间。再次入水后，需要重新累计前置浸水时间，再完成转化倒计时。先泡水触发转化、再转移到干燥处理区等待成品的流程不再成立。

## 骷髅开始发抖前的细雪停留时间能够保存

骷髅在细雪中转为流浪者也分为前置冰冻和发抖转化两个阶段。新版新增前置阶段的存档数据。

### 差异出现的场景

骷髅在细雪中已经累计一部分停留时间，但尚未开始发抖，此时卸载实体或退出世界，随后重新加载。

### 版本变化

- Snapshot 3：不保存前置冰冻时间，重新加载后从头累计。
- Snapshot 4：将这段时间存为 `FreezingTime`，重新加载后接着累计。已经开始发抖后的转化倒计时此前就能保存。

## 坐垫作为燃料的燃烧时间缩短

坐垫仍能为熔炉、高炉和烟熏炉供能，但每个坐垫提供的燃烧时间降为原来的四分之一。

### 差异出现的场景

使用未经修改的坐垫作为燃料，加工耗时为普通熔炉 200 游戏刻、快速炉 100 游戏刻的标准配方。

### 版本变化

- Snapshot 3：一个坐垫在普通熔炉中燃烧 200 游戏刻，在高炉和烟熏炉中燃烧 100 游戏刻，足够加工一个物品。
- Snapshot 4：分别只燃烧 50 和 25 游戏刻，需要四个坐垫才能完成一次标准加工。其他原版燃料的标准燃烧时间保持原值。

## 熔炉按物品组件识别燃料，并支持燃料控制加工速度

烧炼燃料改由 `minecraft:cooking_fuel` 组件定义，燃烧时间与加工速度可以分别配置。燃料槽和漏斗输入也按这一组件识别燃料。

### 差异出现的场景

用组件或数据包修改某堆物品的燃料资格与速度；或把 Snapshot 3 中仍在燃烧的高炉、烟熏炉存档升级到新版。

### 版本变化

- Snapshot 3：燃料资格和燃烧时间来自物品类型及燃料标签，高炉和烟熏炉统一将燃烧时间减半，并以固定的两倍速度加工。修改相关木制品、船等标签可以改变燃料资格。
- Snapshot 4：添加或移除燃料组件可以改变单独一堆物品的燃料资格，旧标签不再自动控制它。组件通过数值提供器分别给出燃烧时间与速度倍率；更换燃料导致速度变化时，当前加工进度按已完成比例换算。原版普通燃料仍让高炉和烟熏炉以两倍速度工作。若燃烧时间提供器不存在，熔炉仍接受带组件的物品，但不会消耗它来点火。

### 实际影响

升级时，已经在燃烧的高炉和烟熏炉缺少新的 `speed_multiplier` 存档字段，加载后默认为 1。当前物品可以按已保存的旧总时间完成，但随后重算加工时间时会使用一倍速度，直到消耗下一份燃料才恢复原版两倍速度。若旧燃料烧完前更换输入，也会提前重算。这会暂时改变出货间隔和这份剩余燃料的产量。

## 酿造台按组件识别燃料并读取次数与速度

酿造燃料改由 `minecraft:brewing_fuel` 组件决定，组件可以分别指定可用次数与酿造速度。

### 差异出现的场景

通过数据包或物品组件改变酿造燃料，或者让燃料组件引用不存在的次数提供器。

### 版本变化

- Snapshot 3：燃料槽及漏斗输入使用酿造燃料标签判断物品，每次消耗一份燃料固定补充 20 次酿造；物品组件不能单独改变这套规则。
- Snapshot 4：燃料槽及漏斗输入检查酿造燃料组件，旧酿造燃料标签已移除。次数和速度由组件引用的数值提供器计算；原版烈焰粉仍提供 20 次酿造。若次数提供器缺失，次数取 0，但仍消耗燃料，因而可能逐刻耗尽整堆燃料而不开始酿造。

## 村民不再通过小麦分享分支扔出普通小麦，分享时保留物品数据

村民的食物识别和繁殖食物计分改用 `minecraft:villager_food` 组件，分享物品时也改为拆分原物品堆。

### 差异出现的场景

农民在交流时拥有超过半组普通小麦；村民分享带自定义名称等组件的食物；或数据包改变物品的村民食物组件。

### 版本变化

- Snapshot 3：小麦分享分支可以扔出普通小麦。分享食物时按物品类型重新创建物品堆，自定义名称等组件会丢失。繁殖食物按面包、胡萝卜、马铃薯和甜菜根四种固定物品计分。
- Snapshot 4：小麦分享分支额外要求小麦带有村民食物组件，而原版小麦没有它，因此普通小麦不再被这一分支扔出。分享时保留原物品堆的数据。村民按每堆物品的 `villager_food.nutrition` 计分，并允许拾取带该组件的物品；原版四种食物分值不变，移除其组件后不再供村民进食，给其他物品添加组件则可参与进食与分享。

## 床必须具有另一半才能使用

新版在睡觉、设置重生点和触发床爆炸之前检查床的另一半，并在玩家成功开始睡觉时补充位置同步。

### 差异出现的场景

使用命令等方式留下单独床头，或相邻位置没有构成一头一尾的同种床，然后对其使用交互键；正常完整的床则用于比较开始睡觉时的同步。

### 版本变化

- Snapshot 3：异常床仍可能让玩家睡觉、设置重生点，或在不允许睡觉的维度触发爆炸。成功开始睡觉时没有本次新增的位置确认。
- Snapshot 4：另一半必须是相同种类的床，且床的部分属性与当前一半相反；检查失败就不再执行上述操作。玩家成功开始睡觉时，服务器还会立即发送位置确认，使客户端位置与服务器设置的睡眠位置一致。

## 坐垫放置改用实际碰撞表面并扩大支撑检查范围

新版对炼药锅、漏斗和堆肥桶重新计算坐垫的点击位置，并扩大坐垫向下寻找支撑的范围。

### 差异出现的场景

视线能命中上述方块的内部表面，或坐垫支撑面附近的碰撞形状来自更下方的方块。

### 版本变化

- Snapshot 3：使用最初选取方块得到的点击位置，支撑检查向下覆盖的范围也较小。
- Snapshot 4：按目标方块的实际碰撞形状重新计算点击位置，使坐垫可以按命中的内部表面高度放置。支撑检查向下多扫描 1/8 格，可以检查实际形状向上突出到支撑面附近的下方方块。

## 坐垫会受到火焰伤害并被雷击破坏

新版在坐垫的环境检查中加入火焰伤害，并为坐垫单独实现雷击破坏与掉落保护。

### 差异出现的场景

坐垫接触火焰、直接放置在火焰中，或遭到雷击。

### 版本变化

- Snapshot 3：定期环境检查只处理流体，不主动检查火焰。继承的雷击处理为空，雷击不会直接破坏坐垫。
- Snapshot 4：定期检查会施加火焰伤害，刚放进火焰的坐垫会立即检查。雷击直接破坏坐垫，并按实体掉落规则掉出对应颜色的坐垫物品；该掉落物在 20 游戏刻内免疫伤害，避免被同次雷击的后续伤害摧毁。
