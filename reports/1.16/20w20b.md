# Minecraft 20w20b 变更分析

- 上一个版本：20w20a
- 当前版本：20w20b

## 独立服务器恢复正常启动

本次修复调整了独立服务器启动时的初始化顺序，使服务器能够完成启动并加载世界。

### 差异出现的场景

在新的 Java 进程中启动独立服务器，且没有其他程序预先初始化 Minecraft 的游戏内容。这一问题发生在读取世界之前，因此已有存档和准备创建新世界的服务器都受影响。

### 版本变化

- 20w20a：启动入口位于服务器类本身。执行入口前，该类就会构造默认世界生成设置，提前触发地形特征、实体和注册表之间的初始化依赖，导致启动崩溃，无法进入世界或接受玩家连接。
- 20w20b：启动入口移至单独的类，先初始化并校验游戏内容，再读取服务器配置和世界。在已接受 EULA、配置及存档正常的条件下，可以继续完成服务器启动。

这也恢复了独立服务器的启动辅助功能：`--help` 可以显示帮助后退出；`--initSettings` 可以初始化 `server.properties` 和 `eula.txt` 后退出。旧版在进入这些参数的处理分支之前，就已受到服务器类初始化故障的影响。

## 显式指定服务器入口类的启动脚本需要更新

若服务器启动脚本直接指定 Java 主类，20w20a 使用的 `net.minecraft.server.MinecraftServer` 在 20w20b 已不再提供 `main` 方法，需要改为 `net.minecraft.server.Main`，否则 Java 无法找到启动入口。

代码出处：20w20a 的[原入口类和方法](https://github.com/TISUnion/guardian/blob/f03bb1ededc0056052f78a76b90b091a504fcc70/src/main/java/net/minecraft/server/MinecraftServer.java#L940)；20w20b 的[新入口类和方法](https://github.com/TISUnion/guardian/blob/214ba1e735b1c4675ba216af3c1f488f40fa3871/src/main/java/net/minecraft/server/Main.java#L32)。
