# Minecraft 25w03a 变更分析

- 上一个版本：25w02a
- 当前版本：25w03a

## 常规自然生成恢复，刷怪场重新产出生物

在已加载区块内，生物种类由当前生物群系或结构的生成列表选定；生成前还会检查这个种类是否允许出现在具体落点。

### 差异出现的场景

玩家附近存在满足距离、亮度、空间、生物数量上限等条件的自然生成位置，包括普通刷怪场和依靠结构生成列表的刷怪场。

### 版本变化

- 25w02a：检查时把生物生成条目与带权重的包装对象比较，结果始终不匹配，常规区块自然生成在此处被拒绝。
- 25w03a：改为比较包装对象内部的生物生成条目，满足其余条件时可以正常生成。

### 实际影响

通过常规自然生成运行的刷怪场恢复产出，周围世界也重新补充这一路径生成的生物。区块首次生成时放置动物、刷怪笼和独立的特殊生成器采用其他调用路径，不属于这次恢复的范围。

## 跌落伤害改为向下取整

生物的跌落距离改用双精度累计，最终伤害也从向上取整改为向下取整，影响摔落削血装置和带有减伤倍率的落点。

### 差异出现的场景

生物落地，累计跌落距离超过其安全跌落距离；没有其他免伤效果。计算示例中的“距离”指实体实际累计的跌落距离。

### 版本变化

- 25w02a：将“超出安全距离的部分 × 落点倍率 × 跌落伤害倍率”向上取整。
- 25w03a：先给距离加上 `0.000001` 的浮点误差补偿，再将同一乘积向下取整。例如默认安全距离为 3、伤害倍率为 1 时，累计下落 3.5 格从 1 点伤害变为 0 点，4.5 格从 2 点变为 1 点。

对干草捆、蜂蜜块等有伤害倍率的落点，结果同样改为向下取整。朝上的滴水石锥尖端给距离额外添加的数值由 2 改为 2.5，再乘 2；这一补偿与新的取整方式共同决定最终伤害。落地粒子的出现门槛和数量也改用取整后的超额距离。

### 实际影响

依赖精确剩余生命值的摔落装置，尤其是落点位于半格高度或使用减伤方块的装置，会得到不同的削血量。此次取整变化针对生物承受的跌落伤害；下落中的铁砧、滴水石锥等砸中其他实体时，仍采用其自身的下落方块伤害公式。

## 移除潜影盒不再散落其中的物品

25w02a 把潜影盒也按普通容器执行移除散落，而且散落时会取空原有物品堆；25w03a 为潜影盒取消这一步。

- 生存模式玩家打破装有物品的潜影盒时，25w02a 先散落盒内物品，再计算潜影盒掉落，得到的是空盒和散落物品；25w03a 只掉落保留原有内容物的潜影盒。
- 创造模式玩家打破非空潜影盒时，25w02a 先生成保留内容物的盒子物品，移除时又散落原盒内物品，会额外复制内容物；25w03a 只保留带内容物的盒子掉落，不再复制这一份。

这也影响直接替换潜影盒方块的操作：新版不会再单独通过普通容器移除回调散落内容物；是否留下潜影盒物品取决于具体替换方式本身是否执行掉落。

## 用桶重新捕获美西螈会丢失颜色

### 差异出现的场景

用普通水桶捕获一只非粉红色美西螈，再把它放回世界，包括稀有的蓝色美西螈。

### 版本变化

- 25w02a：捕获时把美西螈的变种写进桶，放出后保持原来的颜色。
- 25w03a：变种改存为物品组件，但捕获代码错误地从新生成的桶自身读取该组件，没有读取被捕获的美西螈。普通捕获所得桶不含变种，放出时美西螈保留初始化的 `lucy` 变种，即粉红色。

已有旧版美西螈桶在世界升级时会把原变种转换为新组件，因此可以保持首次放出时的颜色；在新版再次用桶捕获后，仍会遇到上述丢失。年龄、生命值等其他桶数据没有因这一处错误被一起删除。

## 骨粉恢复增加花簇数量，草方块能选择多种花卉配置

- 对少于四簇的粉红色花簇或野花簇使用骨粉，25w02a 会立即掉落一个对应物品，地面花簇数量不变；25w03a 会先把地面数量增加一簇，达到四簇后再使用骨粉才掉落物品。使用低密度花簇直接生产掉落物的装置，前几次骨粉现在用于补满地面。
- 对草方块使用骨粉，在生物群系具有多个花卉生成配置时，25w02a 固定使用列表第一项，25w03a 每次进入花卉生成分支时随机选一项。桦木森林等同时包含野花簇和其他花卉配置的生物群系，骨粉花场可得到的花卉及其比例因此改变；这里是配置之间等概率抽选，并不表示所有花卉物品等概率。

## 水、熔岩和细雪按实际接触处理燃烧

实体移动过程中接触的方块与流体，用于决定点燃、熄灭及熔岩伤害。新版将流体判定与方块判定分开。

### 差异出现的场景

燃烧实体快速穿过含水方块，或只擦过浅层水、熔岩所在方块的上部空间；也包括一段移动同时经过火焰和灭火介质的情况。

### 版本变化

- 25w02a：移动路径的燃烧处理按方块种类识别普通水、气泡柱和熔岩；流体所在方块的整个范围参与判断，含水的其他方块不会在这一轮按水处理。
- 25w03a：水和熔岩按流体实际高度形成的体积检测，含水方块里的水也可以参与灭火。实体只经过流体上方空隙时，不再因为经过其所在方块而被这一判定熄灭或受到熔岩处理。

新版把水和细雪的熄火集中到移动路径处理，删除了早先基于水状态直接清火和生物细雪状态的重复熄火处理。旧版基础实体更新中额外的一次熔岩伤害调用也被删除，实际接触熔岩时仍由移动接触处理施加伤害；矿车自己的熔岩处理仍然保留。

熄灭声音改为在处理前后确实从燃烧变为未燃烧时播放，避免按中间接触状态播放；服务器直接广播该声音，带有静音标记的实体也不再通过通用实体声音入口抑制它。

## 鞍成为真正的装备槽

鞍从猪、炽足兽的布尔状态和马类的独立物品栏，统一迁移到 `saddle` 装备槽。

### 差异出现的场景

给猪、炽足兽或马类装备带有自定义名称、附魔等组件的鞍，使用发射器装鞍，或用命令读取、替换鞍。

### 版本变化

- 25w02a：猪和炽足兽只记录“已装鞍”，死亡时生成一件普通鞍，原鞍的名称等组件丢失；马类的鞍另存于独立物品栏，命令槽名为 `horse.saddle`。
- 25w03a：这些实体保留实际装备的鞍物品及其组件，死亡时走通用装备掉落处理。猪和炽足兽因此可以返还原本带组件的鞍；带有消失诅咒等禁止装备掉落效果的鞍也受这一通用规则约束。命令槽名改为 `saddle`，可以统一操作猪、炽足兽和马类。

发射器装鞍改用通用装备逻辑，会给成功装备的生物标记持久存在，防止其因距离消失。普通手动装鞍只保证鞍的掉落，不附带这一持久标记。成年、存活、马类需要驯服等装鞍条件仍由目标检查。

实体装备 NBT 也统一改为 `equipment`，例如 `equipment.saddle`、`equipment.mainhand` 和 `equipment.head`。旧世界的装备和鞍有数据转换；实时执行的 `/summon`、`/data` 以及检查旧 `ArmorItems`、`HandItems`、`SaddleItem`、`Saddle` 路径的函数，需要采用新结构。

## 装备目标限制开始约束更多穿戴操作

对于自定义了 `equippable.allowed_entities` 的物品，25w02a 的玩家右键穿戴、玩家护甲栏手动放入，以及生物拾取装备，没有统一检查允许的实体类型；25w03a 在这些入口检查目标是否允许装备。目标不在允许列表时，不能再靠这些入口穿上或拾取该装备。普通鞍也因此不会被僵尸当作普通手持物拾起。

`equippable` 新增 `equip_on_interact`，允许物品在右键生物、且目标装备槽为空并符合限制时直接装备到目标身上；普通鞍通过这一能力完成手动装备。马类物品栏的鞍槽现在也使用通用装备槽，因此带有绑定诅咒效果的自定义鞍，非创造模式玩家不能从该槽取出。

本版另有一个自定义物品边界问题：玩家的槽可用性检查改为接受 `body`、`saddle`，但玩家物品栏并未增加这两个实际存储槽。如果把允许玩家使用的自定义物品配置为这两种槽并右键穿戴，新版会消耗手中物品，却没有实际保存装备；旧版会拒绝这一步。原版普通鞍的允许目标列表不含玩家，不触发这一情况。

## 铁轨状态变化与活塞移动补回移除侧的更新

- 同一位置的铁轨只改变朝向、坡度、充能等状态时，25w02a 不执行铁轨的移除侧邻居更新；25w03a 也执行这一更新。坡道原状态会更新上方邻居，动力铁轨、探测铁轨、激活铁轨等直轨类还会更新自身位置及下方邻居，改变邻接电路收到更新的范围。

## 同时按前进和横移可以开始疾跑

在陆地满足饥饿值等其他疾跑条件、尚未疾跑时，25w02a 要求移动输入的前进分量至少为 0.8；同时按前进和横移后，归一化的前进分量约为 0.707，无法通过这一检查。25w03a 改为要求存在前进输入，且整个移动向量长度至少为 0.8，因此可以直接在斜向行走时开始疾跑。

潜行防坠落的支撑检测也作了细微调整：检测范围在水平方向各内缩 `0.0000001` 格，向下额外探测的容差从约 `0.00001` 格降为 `0.0000001` 格。普通搭路的规则不变，但与支撑边缘相差这些微小距离的极限位置，可能从“仍有支撑”变为“会跌落”，潜行移动因此更早被截短。

## 传送俯仰角与异常实体状态处理

## 物品可通过组件指定生成实体的变种

25w02a 主要通过 `entity_data` 或桶里的变种 NBT 指定实体外观。25w03a 增加猫、狼、狐狸、青蛙、猪、马、羊驼、美西螈、鹦鹉、兔子、哞菇、鲑鱼、热带鱼、绵羊、潜影贝、村民和画对应的组件，生成实体时会读取其支持的组件。

例如带 `sheep/color="red"` 的绵羊刷怪蛋生成红羊，热带鱼桶通过三个独立组件指定花纹及两种颜色。普通捕获所得热带鱼桶、鲑鱼桶保留原来的鱼的表现；其保存位置改为组件。旧桶、画物品里的变种在世界升级时有相应转换。若同时提供组件和合法的 `entity_data`，后应用的实体 NBT 可以覆盖组件结果。

这一接口只对具体实体实现的字段生效。本版村民实现了 `villager/variant`，僵尸村民没有对应的组件读写实现，不能据此把该组件当成所有村民类实体通用的变种入口。

另外，25w03a 放置画、物品展示框和荧光物品展示框时也执行通用物品组件应用，因此铁砧命名等 `custom_name` 组件会传给放置出的实体；25w02a 的这个放置入口只应用自定义实体 NBT，不传递物品名称。

## 实体变种谓词迁移到组件，旧颜色条件不再生效

25w03a 的实体谓词新增 `components`，按照实体提供的组件值进行精确匹配，例如 `"components":{"minecraft:sheep/color":"red"}`。旧的猫、狼、青蛙等变种专用 `type_specific` 谓词被移除，继续使用这些已删除类型的数据包会遇到解析失败；旧绵羊谓词仍存在，但删除了 `color` 字段，保留旧字段不会继续限制颜色。

旧版可用变种标签或变种集合匹配的部分谓词，迁移后不能直接把标签或列表填入单个组件值中，需要以其他谓词组合表达。原版绵羊掉落、剪毛战利品、蛙明灯条件和对应进度已同步采用新组件条件，其正常玩法结果保持一致。

实体累计跌落距离的 NBT 同时从 `FallDistance` 改为双精度的 `fall_distance`。旧存档有转换，直接查询、修改或匹配旧字段的命令不会自动改写。

## 只改方块实体 NBT 的放置命令会保存并同步结果

当 `/setblock`、`/fill` 等放置命令保持相同方块状态、只改变方块实体 NBT 时，25w02a 虽然在内存中加载新数据，却没有在这一分支标记保存和通知客户端。25w03a 发现加载前后数据不同后，会标记该方块实体已修改，并把位置加入区块同步。

因此，命令改写容器等方块实体数据后，客户端能够收到更新，数据也不会仅因这个分支漏记修改而在区块重载后恢复旧值。

## 自定义武器与悬停文本字段改名

- `weapon` 组件中每次攻击损耗的字段由 `damage_per_attack` 改为 `item_damage_per_attack`。旧版例如填 5 会在每次攻击消耗 5 点耐久，新版继续使用旧字段时不再读取它，改用默认值 1；原版武器的默认行为不因这次字段改名改变。
- `hover_event` 中 `show_text` 的内容字段由 `text` 改为 `value`。实时命令或数据包继续提供旧 `text` 字段时，不能再按新版结构解析这段悬停事件。更早版本的旧文本数据转换也相应改为生成 `value`。

## 正常游戏中开放 GameTest 和方块测试

25w02a 的 `/test` 和测试更新只在开发环境注册、执行；25w03a 在正常游戏中开放，`/test` 要求权限等级 2。管理员可以用命令运行、重复运行、定位、重置或清除测试，并通过数据包的 `test_instance`、`test_environment` 定义结构和测试环境。

新增的 Test Block 和 Test Instance Block 进入管理员物品栏，放置及编辑受管理员方块权限约束。Test Instance Block 可以保存、加载并运行关联结构；方块式测试通过 START 模式输出 15 强度信号，ACCEPT、FAIL 和 LOG 模式在收到红石上升沿后分别参与成功、失败和日志判定。此版本 START 的触发代码没有安排复位计划刻，因此不能把它视为会自动结束的固定长度红石脉冲。

测试环境还可以设置游戏规则、时间、天气，以及运行设置和清理函数。这些设置作用于实际世界：游戏规则清理时恢复的是默认值，而非运行前的自定义值；时间没有自动恢复步骤，天气清理重置天气周期。重置或清理测试也会重新放置、清空测试结构区域，所以在现有装置旁运行这些命令会实际改变该区域和环境。

加载 Test Instance Block 的结构前，新版还会直接移除结构范围内的非旁观实体，范围包括普通玩家；这不是一次正常死亡处理。测试批次完成或验证遇错停止时，运行器会清除所在维度全部强制加载区块记录，包括运行测试之前由 `/forceload` 设置的区块，而不仅是测试自己的区块。

## 物品模型、实体位置与经验球显示调整

25w03a 为物品模型的选择器新增 `minecraft:component`，资源包可以按可序列化组件的完整值选择模型，而不必仅依靠既有的少数专用选择属性；缺少对应值或没有匹配项时使用回退模型。原版既有物品的功能不因此改变。

没有专用位置插值器的实体，例如掉落物和普通投射物，收到常规位置或旋转同步时，25w02a 会连同上一次显示位置一起跳到目标；25w03a 只更新当前坐标和角度，保留用于帧间过渡的旧值，减少同步时画面直接跳动。

幼年北极熊模型的变换顺序由“先整体缩放，再调整幼崽比例”改为相反顺序，头部相对身体的显示位置随之小幅调整。

经验球的经验值改为同步实体数据。使用命令改变已存在经验球的 `Value` 时，25w02a 的客户端外观可以继续保持旧数值对应的大小，25w03a 会同步新数值并更新显示；服务器实际给予的经验值仍以自身数据为准。
