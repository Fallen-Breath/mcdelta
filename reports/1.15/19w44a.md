# Minecraft 19w44a 变更分析

- 上一个版本：19w42a
- 当前版本：19w44a

## 工具损坏的最后一次采集保留原工具的掉落效果

玩家挖坏方块时，新版先保留挖掘前的工具，再扣除耐久并计算掉落。工具恰好在这次挖掘中损坏时，方块仍能识别其附魔和工具类型。

### 差异出现的场景

玩家使用带有精准采集、时运等效果的工具，或者剪刀，挖掘一个会消耗其最后一点耐久的方块，并且满足该方块的采集资格。

### 版本变化

- 19w42a：先扣除耐久。工具损坏后，交给方块掉落逻辑的是空物品，最后一次采集会失去精准采集、时运或剪刀等工具条件。
- 19w44a：掉落逻辑取得挖掘前的工具副本。即使工具随后损坏，这次采集仍按原工具计算。

这也影响精准采集之后的方块处理。例如，用最后一点耐久的精准采集工具挖冰时，新版保留冰的掉落，且不会执行非精准采集导致的化水处理；挖蜂巢或蜂箱时，新版不会因为工具损坏而把巢内蜜蜂按非精准采集方式紧急放出。巢外附近蜜蜂的愤怒仍由独立逻辑处理。

## 潜影盒不再与栅栏、墙、铁栏杆和玻璃板连接

栅栏、墙、铁栏杆和玻璃板会根据相邻方块决定是否生成连接臂。新版将原色及全部染色潜影盒列为连接例外，改变这些方块朝向潜影盒一侧的形状。

### 差异出现的场景

上述方块与潜影盒水平相邻，并在放置或收到相应邻居更新时重新计算连接状态。已有结构保存在方块状态中的连接方向，也在重新计算后体现变化。

### 版本变化

- 19w42a：潜影盒的完整侧面可使相邻方块生成朝向它的连接臂。
- 19w44a：相邻方块不再朝潜影盒生成连接臂，相应方向的碰撞部分随之消失；墙的连接变化还可能改变中间立柱的显示与碰撞。

### 实际影响

使用潜影盒配合这些方块围挡实体、约束移动路径或限定物品通道的结构，在连接更新后会形成不同的碰撞边界。

## 蜂蜜瓶可以堆叠，蜂蜜块可以重新装瓶

蜂蜜瓶的堆叠上限提高到 16，同时新增用玻璃瓶将蜂蜜块还原为蜂蜜瓶的配方，改变蜂蜜的储存、分类与饮用方式。

### 差异出现的场景

储存、运输、分类或饮用蜂蜜瓶，以及把已经合成的蜂蜜块转回可饮用的蜂蜜。

### 版本变化

- 19w42a：蜂蜜瓶每格只能放一个；蜂蜜块没有转回蜂蜜瓶的合成配方。
- 19w44a：蜂蜜瓶每格最多放 16 个。工作台中一个蜂蜜块与四个玻璃瓶可以无序合成为四个蜂蜜瓶，取得蜂蜜块即可解锁此配方。

新版生存模式玩家从一叠蜂蜜瓶中喝掉一个后，会保留手中的其余蜂蜜瓶，并把一个玻璃瓶放入背包；背包装不下时将玻璃瓶掉到地上。喝完最后一个时，手中直接变成玻璃瓶。

### 实际影响

同样数量的蜂蜜瓶占用更少容器槽位，运输和存储容量随之增加。依赖蜂蜜瓶不可堆叠这一特征的分类方式会改变，容器的比较器信号也会降低。例如，一个其余槽位全空的漏斗里只有一个蜂蜜瓶时，比较器输出从 3 变为 1；新版需要 16 个蜂蜜瓶才相当于旧版一个蜂蜜瓶的槽位占用比例。蜂蜜块还可以作为可还原的蜂蜜储存形式，取出后用玻璃瓶重新装瓶。

## 压缩与拆分配方调整解锁条件

压缩和拆分配方的解锁条件改为检查各自所需的原料，改变配方书中的发现时机。启用 `doLimitedCrafting` 时，解锁状态也决定玩家能否使用相应配方。

### 差异出现的场景

玩家尚未解锁相应配方，取得压缩原料、压缩后的方块或可拆分的锭。涉及蓝冰、浮冰、骨块、煤炭块、钻石块、干海带块、绿宝石块、金块、干草块、铁块、青金石块、黏液块、红石块，以及金粒或铁粒合成对应锭的配方。

### 版本变化

九合一压缩配方：

- 19w42a：许多配方要求背包中出现一叠至少九个原料才解锁；干海带块的配方还可以因持有干海带块本身而解锁。
- 19w44a：取得一个对应原料即可解锁。干海带块的配方需要取得干海带，不再仅因持有干海带块而解锁。

相反方向的拆分配方：

- 19w42a：可因持有一叠至少九个散装材料提前解锁，即使尚未取得要拆分的方块或锭。
- 19w44a：需要持有真正要拆分的方块或锭才解锁。

已有配方的材料数量和产出不变；在有限合成规则下，上述解锁时间的提前或推迟也会相应改变配方开始可用的时间。

## 多种树木调整生长前的空间检查

树木生成前会检查周围空间，遇到不能通过检查的障碍物便取消生成。新版将几类小型树木的检查范围与树冠放置半径分开，改变自然生成和树苗生长所需的净空；树冠本身的放置形状没有随之缩放。

### 差异出现的场景

树木周围有石头、建筑方块等不能通过空间检查的障碍物。以下以树木起点所在层为第 0 层，检查一直进行到本次选定树高之上的一层；比较时保持树高、树冠半径等随机选择相同。

### 版本变化

普通小橡树、白桦、小型丛林树及沼泽橡树：

- 19w42a：按选定树高、树冠半径和当前层计算检查范围，较低层通常检查得更宽，底部也会检查树干周围较大区域。
- 19w44a：第 0 层只检查树干所在的一列；第 1 层起固定检查以树干为中心的 3×3 区域。

金合欢：

- 19w42a：第 0 层只检查中心；接近顶部时检查 5×5，其他较低层通常检查 3×3。
- 19w44a：第 0 层只检查中心，其余高度均检查 5×5。较低处距离树干两格的障碍物也会阻止生长。

单株云杉的两种树形：

- 19w42a：下部只检查中心，到选定的树冠起始高度后扩大到本次树冠半径。
- 19w44a：第 0、1 层只检查中心，第 2 层起固定检查 5×5。树冠较高时更早检查树干周围；原先选中较大树冠半径的尝试，则在高处减少检查范围。

### 实际影响

普通小橡树、白桦和小型丛林树更容易在邻近建筑或受限空间里长成；检查范围外仍有障碍物时，树叶放置会跳过不能替换的位置。金合欢树场的低层侧向净空要求加大，单株云杉则按新的分层范围判断障碍物是否阻止生长。

这些变化也会改变新生成区域中部分树木能否成功生成，继而影响后续随机生成结果。已经存在的树木不会被重建；大型橡树、深色橡树和 2×2 巨型树不使用本次修改的这套检查。

## 创造模式背包中丢出的物品改为通常的五分钟寿命

创造模式背包有专用的向外丢弃处理。新版移除了这条路径对掉落物年龄的特殊设置，使其具有通常的消失时间。

### 差异出现的场景

玩家通过创造模式背包界面向外丢出物品，掉落物持续被加载并正常计时，期间没有被拾取、销毁或通过合并改变年龄。

### 版本变化

- 19w42a：新掉落物的年龄直接设为 4800，再经过 1200 游戏刻便消失；正常刻速下约为一分钟。
- 19w44a：新掉落物从通常的初始年龄开始计时，经过 6000 游戏刻才消失；正常刻速下约为五分钟。

利用创造背包供料的物品运输、展示或清理装置，因此有更长的拾取和滞留时间。普通生存模式丢弃不受这项修改影响。

## 创造飞行关闭时不再同时展开鞘翅

创造飞行切换和鞘翅展开都会使用跳跃输入。新版记录同一次输入是否已切换飞行状态，避免关闭创造飞行后立即继续展开鞘翅。

### 差异出现的场景

玩家穿着可用的鞘翅，在空中双击跳跃键关闭创造飞行，并满足开始滑翔的条件。

### 版本变化

- 19w42a：关闭创造飞行后，同一次输入继续检查鞘翅展开条件，可以立即进入滑翔。

## 区块和村民兴趣点的磁盘写入转到后台执行

区块和村民兴趣点数据原本在保存调用中直接写入区域文件。新版将压缩与写盘交给后台线程，改变保存操作的等待时间和命令返回时所代表的完成状态。

### 差异出现的场景

世界进行自动保存、区块卸载、执行保存命令，或保存床、工作站等村民兴趣点数据。

### 版本变化

- 19w42a：调用区块或兴趣点的写入操作时，直接进行区域文件写入，调用方需要等待该次压缩与写盘结束。
- 19w44a：先把已经序列化的数据交给后台线程，再返回调用方。同一区块尚未写出的多次保存可以合并为最新一份；在写出之前重新读取该区块时，会优先读到待写的最新数据。

后台处理减少了这些磁盘写入直接占用服务器刻处理时间的部分，但区块数据的序列化仍在原有保存流程中进行，读盘请求也仍要等待结果。

### 实际影响

普通 `/save-all` 完成时，新版可能仍有数据等待后台写出，不能再把它的返回直接当作所有区域文件已完成本轮写入。`/save-all flush` 会额外等待区块写入队列完成，正常关闭存储时也会写完剩余的已提交任务再关闭文件。

区块数据和兴趣点数据使用各自的后台线程。本次新增的 `flush` 等待只连接到区块线程，兴趣点的单区块保存方法仍只是提交后台任务，因此 `/save-all flush` 返回时不保证兴趣点队列也已经写完。正常关闭世界时会分别关闭并等待两套存储。后台写盘异常会记录到日志；等待区块队列结束也不等于证明每次写入均成功。

## 不存在的谓词不再通过取反条件放行

命令和实体选择器都能引用数据包中的谓词。新版改变了引用不存在谓词时的处理，取反条件也不再因默认的假值而放行。

### 差异出现的场景

数据包缺失、谓词加载失败或命令写错资源位置，使 `execute` 或实体选择器引用了不存在的谓词 ID。

### 版本变化

`execute if predicate <不存在的ID>` 及其 `unless` 形式：

- 19w42a：将不存在的谓词视为假，`if` 不通过，`unless … run …` 因取反而执行后续命令。
- 19w44a：直接报告未知谓词错误，`if` 和 `unless` 都不能继续执行后续命令。

`@e[predicate=!<不存在的ID>]`：

- 19w42a：默认假值取反后为真，实体通过这一项筛选，再由选择器的其他条件决定最终结果。
- 19w44a：取反前便拒绝不存在的谓词，这一项筛选不匹配任何实体。未取反的不存在谓词仍不匹配实体。
