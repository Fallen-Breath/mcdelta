# Minecraft 19w46b 变更分析

- 上一个版本：19w46a
- 当前版本：19w46b

## 蜜蜂丢失寻路目标时不再引发实体更新崩溃

蜜蜂飞向蜂巢或记住的花朵时，新版会先检查目标坐标是否仍然存在，再继续寻路。

### 差异出现的场景

蜜蜂的回巢或返回花朵任务仍在执行，但保存的目标坐标已被清除，并且本次更新需要重新选择飞行落点。例如，蜜蜂接近已经满员的蜂巢时，进入蜂巢的检查会清除原有蜂巢坐标；如果回巢任务随后仍执行到重新选点步骤，就会遇到这一情况。

### 版本变化

- 19w46a：当当前路径为空或仍被判定为可到达时，寻路任务会继续使用目标坐标。目标已经被清除且需要重新选点时，会因读取不存在的坐标而抛出异常，造成服务端实体更新崩溃；单人游戏中的内置服务端同样受影响。
- 19w46b：目标坐标不存在时，停止当前导航，并按寻路失败处理，清除相应的蜂巢或花朵记忆，避免从这条路径继续读取不存在的坐标。

## 超平坦预设中不存在的生物群系改为回退到平原

超平坦预设字符串分别指定方块层、生物群系和结构选项。新版在生物群系 ID 不存在时保留平原默认值，避免将空值带入后续的设置保存。

### 差异出现的场景

创建超平坦世界时，在预设输入框中导入方块层有效、但生物群系 ID 格式合法且不存在的字符串，例如 `minecraft:bedrock,2*minecraft:dirt,minecraft:grass_block;minecraft:missing;village`，随后返回自定义界面并点击“完成”。

### 版本变化

- 19w46a：解析时将生物群系设为空值。点击“完成”保存生成设置时，读取生物群系 ID 会引发崩溃。
- 19w46b：记录解析错误并继续使用平原，保留已解析出的方块层和结构选项，上述预设可以正常保存。

此变化作用于创建世界时导入的预设字符串，已经生成的地形不会因此改变。

## 普通聊天恢复在线玩家名补全

聊天输入框根据内容选择命令补全或玩家名补全。新版恢复了不以 `/` 开头时的玩家名候选，并使用光标前的文字确定要补全的单词。

### 差异出现的场景

在普通聊天中输入不以 `/` 开头的文字，光标前的最后一个单词与在线玩家名相匹配，然后按 Tab；光标可以位于整句话末尾，也可以位于句子中间。

### 版本变化

- 19w46a：遇到不以 `/` 开头的内容便提前结束补全更新，不会为当前文字生成在线玩家名候选。
- 19w46b：根据光标前最后一个单词匹配在线玩家名，按 Tab 可以打开候选列表并选择补全。光标后的文字不参与候选匹配。

## 命令方块中带斜杠的命令失去正常补全

命令方块编辑界面在本地解析输入，生成补全和错误提示。新版直接解析整段输入，不再跳过开头的 `/`，使带斜杠的命令在编辑时被识别为错误。

### 差异出现的场景

在命令方块或命令方块矿车的编辑界面中输入 `/say` 等以 `/` 开头的命令。

### 版本变化

- 19w46a：补全解析前跳过开头的 `/`，可以正常获得命令提示。
- 19w46b：开头的 `/` 也被纳入命令名，导致解析错误，失去正常补全。

两版服务端实际执行命令时都会跳过开头的 `/`，因此已经保存的这类命令仍可执行；本次差异发生在编辑过程中的补全和错误提示。

## 补全候选支持旁白朗读

新版为聊天和命令方块编辑界面的补全列表增加旁白反馈，朗读当前候选的序号、候选总数、文本以及存在时的说明。

### 差异出现的场景

系统语音可用，旁白设为“朗读全部”或“朗读系统消息”，并在聊天、命令方块或命令方块矿车的编辑界面中操作非空的补全列表。

### 版本变化

- 19w46a：没有补全候选的专门朗读。
- 19w46b：按 Tab 主动打开候选列表时朗读首项；用方向键、连续 Tab 或鼠标切换到其他候选时，朗读新选中的候选。输入框的旁白内容也会加入当前候选信息。

新版自动弹出候选列表时，不会仅因首项被选中就立即朗读该项；之后切换候选仍会触发朗读。
